# 门禁与轴 · 完整判据

## 一、五道门禁

| 门 | 判据 | 性质 |
|---|---|---|
| **G0** 检索层 | 去重 / 存在性 / 元数据完整 / 版本——**四项全过** | 硬 |
| **G1** 入库 | PMID ↔ DOI **一一匹配** | 硬 |
| **G2** 内容 | **排他性断言 = 0**；缩写首次全展开 | 硬 |
| **G3** 理解 | **逐页一句话说得出** | 硬 |
| **G4** 交付 | 边缘 / 边距 / 四角**全 0** | 硬 |

**硬门禁必须过，不分档。**

### 唯一的回改回路

```
G4 发现问题  →  回 B4 改「制作稿」  →  重新生成
             ✗  不是直接改成品
```

**为什么**：直接改成品的修正，**下次重新生成会被覆盖**——
而且没人会记得上次手动改了什么。

## 二、六条轴

**混着查会互相误报。** 同一个词，讲稿里是对的，幻灯片里就是错的。

| # | 轴 | 在哪查 | 查什么 |
|---|---|---|---|
| ① | **措辞的文体适配** | 写作禁用词清单 | 口语节拍 vs 口语化 |
| ② | **说法准不准** | 内容自检清单八条 | 自足 / 可答 / 有出处 / 不越原文 / 不哄 / 不设问 / 科学表述 / 维度齐 |
| ③ | **像不像他写的** | 身份匹配约束 | 术语层 / 引据层 / 立场层 |
| ④ | **像不像人写的** | 去味清单 | AI 味、套话 |
| ⑤ | **引用与断言** | `check_language.py` | 自足 · 排他性 · 量词 · 缩写 · 数字口径 |
| ⑥ | **身份匹配机检** | `check_persona.py` | 保守 / 越级 / 引据 / 回指 / 书面语 / 长句 |

### ② 与 ③ 最容易混

两者都是「话该怎么说」，但轴不同：

| | **② 不越原文** | **③ 越级表述** |
|---|---|---|
| 问 | **证据强度**——原文有这么强吗 | **立场**——这个口气他拿得住吗 |
| 例 | 「没达标」→「相对疗效尚未确立」 | 「这证明了」→「这项研究提示」 |

> **前者是「别把人家的话说重了」，后者是「别把自己的位置站高了」。**

## 三、内容自检 · 八条标准

| # | 标准 | 一句话判据 |
|---|---|---|
| 1 | **自足** | 这一处**单独**拿出来，读者知道说的是什么吗？ |
| 2 | **可答** | 这个数字/名词，能回答「**这是什么的口径**」吗？ |
| 3 | **有出处** | 这句**排他性断言**，出处在哪？ |
| 4 | **不越原文** | 原文说得有这么强吗？ |
| 5 | **不哄** | 这句是在**解释**，还是在**降智**？ |
| 6 | **不设问** | 我会当众**自问自答**吗？ |
| 7 | **科学表述** | 这是科学措辞，还是口语？ |
| 8 | **维度齐** | 同一组的各项，答的是**同一个问题**吗？ |

### 第 5 条的判据

> **有没有新信息？**
>
> | 降智 | 解释 |
> |---|---|
> | 「**这句话的意思是**：…」——重复已说过的 | 「PV 打在胞体上，**决定神经元什么时候能放电**」——补上缺的那一环 |

## 四、三条使用纪律

**1. 命中 ≠ 要改。**
脚本报「可能」不代表要删——**写证据边界时「可能」是正确用法，写结论时才是逃避**。脚本分不清，人分得清。

**2. 讲稿与幻灯片要求不同。**
同一个词：讲稿要**口语**（节拍保留），幻灯片要**书面**（跳读，没有上下文兜底）。
**用错轴会误报。**

**3. 门禁分两种。**
- **硬门禁**（必须过）：G0 · G1 · G2 · G3
- **软检查**（提示用）：`check_persona` 全部；`check_language` 的启发式项

## 五、排他性断言（硬规则）

以下词一旦出现，**必须能指到具体出处**：

```
唯一  首次  首个  第一个  独创  当前主流  无效  不独特
没有区分力  没人研究过  零篇  从未有人  无一例  没有任何一项
```

> **正向断言错了只是不够好；排他性断言错了是「武断」。**

**若出处是「我们自己的检索」**，必须写明**分层与库名**：

> ✅ 「在 **PubMed / Europe PMC / OpenAlex** 三库交叉检索下，标题级 **0 篇**、
> 标题/摘要级 **3 条中 2 条为会议材料**（已排除），**有效 1 篇**」
>
> ❌ 「**零篇文献**」「**没人做过**」
