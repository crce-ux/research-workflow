**文献调研的完整流程纪律**——核心是「覆盖声明」与四条影响力判读规则。

---

## 它补的是什么

现成的检索与精读 skill 已经很多。本 skill 补三块**它们没有的**：

| # | 补什么 | 一句话 |
|---|---|---|
| 1 | **覆盖声明** | 凡是核查，必须报出「**查了什么**」与「**没查到什么**」 |
| 2 | **影响力指标的归一化读法** | 裸被引数会把最好的新文筛掉 |
| 3 | **证据表的列口径** | IF 标年份、分区标版本——**不写口径等于没写** |

---

## 覆盖声明

```
可识别位置总数 N  →  实际核查 M  →  未能覆盖 K（逐条列原因）
```

| ❌ | ✅ |
|---|---|
| 「引用已全部核实」 | 「28 处引用中核实 26 处；2 处因付费墙未读取，标未核实」 |
| 「已逐篇核对数字」 | 「24 篇中核对 24 篇；其中 3 篇仅读到摘要」 |

> 🔴 **只报「已检查」而不报「没检查什么」，等于假装覆盖完整。**

---

## 四条规则

1. **相关度是门槛，影响力是排序。**
2. **裸被引数不可用，必须按年份归一。**
   实测：某 2026 年新文被引仅 **5 次**，但 **FWCI = 31.2、Top 1%**——用裸被引它会被排到最末。
3. **影响力 ≠ 质量，而且权威的错误更危险。**
4. **外在不该覆盖内在。** 某篇 FWCI 0.47（低于领域平均）的论文，对具体课题仍是关键证据。

## 流程

```
Step 0  检索与筛选（多源并行 + 三级筛选）
   ↓
G0      质控四项：去重 / 存在性 / 元数据完整 / 版本   ← 全过才进表
   ↓
Step 1  证据表（单一数据源 · 12 列）
   ↓
Step 2  逐篇讲解（每个数字回原文对应语句核过）
   ↓
Step 3  综述（正文 [n] ↔ 文末编号表 一一对应）
```
