# G0 · 元数据字段级核对矩阵

> **补什么**：§三 的 G0 只说「元数据完整」——**没说比对哪些字段、什么算错、错到什么程度要拦**。
> 本文给一张可照做的矩阵。
>
> **管什么**：一条文献的**著录**对不对。
> **不管什么**：待检文献**说的对不对**（归 §一 语境核验）。

---

## 〇、⭐ 先做最便宜的检查

**在跑任何多源交叉之前，先做这一步：**

```
对每条有 DOI 的记录，请求 https://api.crossref.org/works/<DOI>
  404  → DOI 本身错了（高度疑似错号）
  200  → 比对返回的标题/作者/卷期页与你的条目
         不一致 ⇒ DOI 张冠李戴（指向了另一篇论文）
```

> **来源方的一条实测**：其 35 条核查中 9 处错误，**7 处由 Crossref 反查抓到**。
> （该数据出自来源方，非本库实测）
>
> 🔴 **顺序纪律**：最便宜的检查**最先做**。先把 DOI 错号这一层清干净，再上多源交叉。

## 一、三级严重度矩阵

### 🔴 Critical —— 必须改

| 检查项 | 判据 | 典型形态 |
|---|---|---|
| 作者**姓名 / 顺序**不符 | 第一作者不同、顺序颠倒、或整条编造 | 姓名形近而误；两位作者顺序颠倒 |
| 作者**漏人** | 条目作者数少于出版方记录 | 5+ 作者文献只录前 3–4 人 |
| **页码差异 ≥ 5** | 完全不匹配 | 起止页整段对不上 |
| **文章号字母误判** | 文章号含字母被写成形近数字 | 字母 `T`/`l`/`O` 被看成数字 `7`/`1`/`0` |
| **标题核心词**不符 | 非大小写 / 标点差异 | 同一作者不同论文 |
| **DOI 指向另一篇** | DOI 可解析但标题作者对不上 | 尾号差一位，指向同卷另一篇 |

### 🟡 Warning —— 建议核对

| 检查项 | 判据 / 处置 |
|---|---|
| **卷归属年 ≠ DOI 年** | 卷年与 DOI 编号年不一致（如卷 2025 / 上线 2024） |
| **Early Access 漂移** | 期刊 Early Access 转正式出版后，卷/期/页/年会变 → ⭐ **一律以 CrossRef 现值为准** |
| 作者**中间名**缺失 / 多余 | 有首字母缩写 vs 有中间名——一般不影响检索 |
| **期号**缺失 | 有卷无期 |
| 页码偏差 **≤ 4** | 细微差异 |
| 出版社名写法差异 | 机构历史名称变更后的新旧写法 |

### 🟢 Info —— 仅供参考

标题大小写 · 期刊缩写 vs 全称 · `and` vs `&` 之类标点差异。

## 二、三条判定纪律

**1. 严重度按「会不会误导读者」切，不按「看起来像不像错」。**
页码差 5 页会让人找不到原文（🔴）；差 1 页不会（🟡）。
**大小写不同几乎从不误导**（🟢）——把它当 Critical 报，会掩盖真正的问题。

**2. 有疑问时以 CrossRef 现值为准。**
尤其 Early Access 转正之后——**你的记录在当时是对的，现在已经过时**，
应标为「旧」而非「错」。

**3. 中文文献不在 Crossref 覆盖里。**
CNKI / 万方**没有可编程接口**，必须人工核——**别因为查不到就默认通过**，
要标成「未核实·需人工」。

---

## 三、批量策略

> 超过 **20 条**时，按 **10–15 条一组**拆给并行子代理，各自独立查询后汇总。
> 实测 35 条用 3 个并行子代理可在一次往返内完成；**串行会慢一个数量级**。

**每条的输出格式**：

```
编号 | 字段 | 你的值 | 源值 | 严重度 | 处置
[N]  | 页码 | 起止页 A | 起止页 B | 🔴 | 改
[N]  | 卷年 | 2025 | 2024 (DOI) | 🟡 | 核对后据 CrossRef 改
```

---

## 四、与 §一 覆盖声明的接口

字段级核对**必须计入覆盖声明**：

```
可识别位置总数 N  →  实际核对 M  →  未能覆盖 K（逐条列原因）
```

**「查不到」要写进 K，不能算进 M。** 中文文献、付费墙、源记录缺失——
都是**核查缺口**，不是通过。
