# 正反样例

六组对照。**左边的过不了 `check_lit.py`，或踩了四条规则。**

---

## 一、覆盖声明

### ❌ 不好

```
已检索 PubMed，共 1240 篇，纳入 18 篇。
```

四处失分：没说**怎么查的**；没说**核查了多少**；
1240 → 18，其余 1222 篇**去哪了**；读过什么深度**一句没提**。

### ✅ 好

```
检索：PubMed 建库至 2026-09-30
检索式：("treatment-resistant schizophrenia"[Title/Abstract] OR TRS[Title/Abstract])
       AND (claustrum[Title/Abstract] OR "default mode network"[Title/Abstract])
可识别位置总数 N = 1240  →  实际核查 M = 1180  →  未能覆盖 K = 60

K 的逐条原因：
  18 篇 无摘要（书目信息不全，无法判断相关性）
  42 篇 仅题录（超过 6 个月未获取全文）

核查深度：
├── 全文 46 篇
├── 摘要 1090 篇   ← 证据深度=摘要
└── 仅标题 44 篇   ← 证据深度=标题，结论不可用

三级筛选：A 类 18 篇（精读）· B 类 27 篇（泛读）· C 类 11 篇（扫读）
纳入证据表 18 篇。
```

**差在**：N→M→K 齐且**相加对得上**（1180 + 60 = 1240）；
K 逐条给原因；**深度分级另计，不合并**。

## 二、检索式

### ❌ 不好

```
检索：treatment resistant schizophrenia claustrum
```

**没有字段限定、没有布尔逻辑、没有时间范围、没有库名。**
换一个人跑，结果完全不同——**上面的检索式**不可复现。

### ✅ 好

```
# PubMed（2026-09-30）
("treatment-resistant schizophrenia"[MeSH Terms] OR "treatment-resistant
 schizophrenia"[Title/Abstract] OR ("clozapine"[Title/Abstract] AND
 "resistant"[Title/Abstract]))
AND ("claustrum"[MeSH Terms] OR "claustrum"[Title/Abstract])

# Web of Science（同日）
TS=(("treatment-resistant schizophrenia" OR TRS) AND claustrum)
```

**差在**：每行前面的注释写了**库 + 日期**；MeSH 与自由词都用了；
别人复制粘贴就能复现。

---

## 三、文献去重

### ❌ 不好

```
PubMed 导出 320 条，Zotero 导出 210 条，合并 530 条。
```

**530 里含重复。** 一份重复就是一次错报的 N——
它会一路带到覆盖声明（N 含重复 → M、K 全歪）。

### ✅ 好

```bash
$ python scripts/dedupe_refs.py 合并导出.csv --out 已去重.csv

dedupe_refs · 合并导出.csv · 读入 530 条
  唯一 412 条 · 去重 118 条

  [DOI] 10.1038/s41380-026-01234
    留 Clozapine response and claustrum connectivity...
    并 Clozapine response and claustrum connectivity in TRS
```

```
合并 530 条 → 去重后 412 条（去重 118）→ 用作 N 的基数。
⚠️ 标题相近的不同版本（预印本 / 正式版）需人工过，脚本只给候选。
```

**差在**：N 用的是**去重后**的数；去重过程打印出来可复核。

## 四、四条规则

| 规则 | ❌ | ✅ |
|---|---|---|
| **1 相关度是门槛，影响力是排序** | 「这本刊 IF 12，先读它」 | 先按主题筛够格的，再按 IF / 分区排序 |
| **2 覆盖声明要说全** | 「纳入 18 篇」（不说 N、M、K） | N=1240 → M=1180 → K=60（逐条原因） |
| **3 出处分类型** | 「软件默认值」当作出处 | 分五类；**软件默认值单列** |
| **4 覆盖要说出来** | 只报最后的数 | 报 **N → M → K** |

## 五、证据表一行

### ❌ 不好

```
| 氯氮平抵抗 | Zhang 2026 | 研究 | 患者 | 氯氮平 | NA | PANSS | 有效 | 6.6 | 一区 |
```

五处：人群没写 N；对照写了 NA 好，但**没写"无对照"是哪一种**；
「有效」不是效应量；IF 与分区**没带年份口径**。

### ✅ 好

```
| 屏状核连接与氯氮平疗效 | Zhang 2026 | 横断面 | TRS 42 例 | 氯氮平 | NA（无对照） |
12 周 ΔPANSS | r=−0.41 (p=0.008) | 单中心；无独立验证集 | 6.6 (2025 JCR) |
中科院医学2区(2025) / JCR Q1 |
```

**差在**：人群带 N、结果是效应量、**IF 与分区都带年份版本**。
