# 覆盖声明细则与四条规则

## 一、覆盖声明 · 完整格式

```
可识别位置总数 N  →  实际核查 M  →  未能覆盖 K（逐条列原因）
```

### 四条细节

| # | 细节 | 后果 |
|---|---|---|
| 1 | **正则 / 关键词搜索 ≠ 完整解析** | 无法解析的格式（图片、扫描件、特殊排版）列为**覆盖缺口** |
| 2 | **未覆盖仍算未核查** | 不得默认通过 |
| 3 | **读取深度要分级** | 全文 / 摘要 / 前三页 / 仅标题——**不同深度不能合并计数** |
| 4 | **计数须与记录对账** | 报出的数字要能对着记录复算 |

### 深度分级的记法

```
24 篇中核对 24 篇
├── 全文 18 篇
├── 仅摘要 5 篇   ← 标「证据深度=摘要」
└── 仅标题 1 篇   ← 标「证据深度=标题」，该条结论不可用
```

## 二、三级筛选

| 等级 | 定义 | 处理 |
|---|---|---|
| **A 类** | 原创 / RCT / 队列，主题直接匹配 | 精读 |
| **B 类** | 原创但有差异 | 泛读 |
| **C 类** | 综述 / 指南 / 方法学 | 扫读、找引文 |

**目标篇数**：每个模块锁定 **15–25 篇**精读核心文献（分区后每区 4–8 篇）。

> 记录每一篇读到了什么深度。

## 三、四条规则 · 完整案例

### 规则 1 · 相关度是门槛，影响力是排序

**顺序反了，就会用高 IF 的离题文章挤掉切题的低 IF 文章。**

操作上分两步：

1. **先按相关度过门槛**——不相关的，无论 IF 多高都出局
2. **门槛内的，再按影响力排序**——决定先读谁

### 规则 2 · 裸被引数不可用

**实测**：某 2026 年新文

| 指标 | 值 |
|---|---|
| 裸被引数 | **5 次** |
| **FWCI**（领域归一化） | **31.2** |
| 被引百分位 | 99.7% |
| Top 1% | ✅ |

**用裸被引排序，这篇 2026 年新文会被排到最末。用 FWCI，它排第一。**

> 老文章积累的时间长，裸被引数因此偏高。
> 归一化指标（FWCI / 百分位）才是可比的。

### 规则 3 · 权威的错误更危险

权威团队也会犯错。而**权威的错误没人质疑**。

**做法**：标出来，**但仍以证据本身为准**。
不能因为「这是某大牛组做的」就跳过核查，也不能因为「这是个小组」就降低采信。

### 规则 4 · 外在不该覆盖内在

**实测反例**：某篇论文

| 指标 | 值 |
|---|---|
| FWCI | **0.47** |
| 被引百分位 | **69.5%**（低于本领域同龄平均） |
| 对本课题 | **关键证据** |

→ **「对本课题关键」与「影响力高」是两件事。**
不要用一个否掉另一个——**内在价值优先**。

## 四、检索预算与上限

| 项 | 默认 | 超限怎么办 |
|---|---|---|
| 检索轮数 | 2–3 轮 | 记「未检出」并**停**，不无限重试 |
| 重试次数 | 3 次 | 记实际错误，**不隐瞒覆盖损失** |
| 独立代理轮数 | 2 轮 | 6 轮不收敛即停 |
| 联网 | **需明确授权** | 未授权时只读本地已有材料 |

**上限的作用**：无限重试会掩盖「这个方向就是没有文献」这个结论。
记下「检索 3 轮未检出」即可。
