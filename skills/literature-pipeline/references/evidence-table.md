# 证据表（单一数据源）

## 定位

**证据表是主数据源。** 讲解、综述、PPT 全部与之对齐。

**任何修改先改证据表，再同步下游。**

---

## 12 列模板（10 列 PICO + 2 列期刊指标）

| # | 列 | 说明 |
|---|---|---|
| 1 | 文献·DOI | 含 PMID/DOI（可溯源） |
| 2 | 作者·年份 | 第一作者 + 年，同年加 a/b |
| 3 | 研究设计 | 系统综述 / 网络荟萃 / RCT / 队列 / 指南 / 专家共识 |
| 4 | 人群 (P) | 诊断 + 样本量 + 关键基线 |
| 5 | 干预 / 暴露 (I/E) | 剂量 / 方式 / 时长 |
| 6 | 对照 (C) | 无对照填 NA |
| 7 | 主要结局 (O) | 预设主要结局 |
| 8 | 关键结果 | **效应量 + 95%CI + p 值** |
| 9 | 局限 | 2–3 条 |
| 10 | 对本课题的意义 | 一句话：支撑哪个论点 |
| 11 | **期刊 IF** | **官方 JCR**，须标年份——`4.4 (2024 JCR)` |
| 12 | **期刊分区** | **中科院分区（标版本）+ JCR 分区并列** |

---

## ⚠️ 第 11、12 列：必须标注口径

| 列 | ❌ 不合格 | ✅ 合格 |
|---|---|---|
| IF | `4.4` | `4.4 (2024 JCR)` |
| IF | 用 OpenAlex 近似值但不说明 | `≈4.4（OpenAlex 近似）` |
| 分区 | `2区` | `中科院医学2区(升级版2025) / JCR Q2` |

**为什么**：

- IF **逐年变动**，不标年份无法复核
- 中科院分区有**基础版 / 升级版**差异，且逐年变动——**不写口径等于没写**
- 近似值与官方值**不能混用**——标出来才能判断可信度

> 查不到的（中文期刊、预印本、新刊）**留空即可**，不要硬填。

---

## 分区组织

**按叙事结构分区**，不是按年份或字母：

```
B1 主题  →  B2  →  B3  →  B4  →  总览框架
```

- 每区前加**分区标题行**（合并单元格）
- 区内部：**按证据等级高 → 低**；同设计按**年份倒序**

---

## 元数据来源优先级

| 情形 | 用什么 | 为什么 |
|---|---|---|
| **PMID 已知** | **PubMed esummary** | 一次性给全卷/期/页/DOI |
| 有 DOI 无 PMID | Crossref 标题搜索 | 定位 DOI |

⚠️ **esummary 优先的理由**：对 article number（如 `14(7):1480`）
esummary **同样返回 pages 字段**，Crossref 对部分不返回；
而且少一跳请求、少一次字段映射错位。

**卷期页缺失**（在线预发表 / article number）→ **留空**，
标注「待出版方确认」，**不硬填**。

## 交付前五道核查

| # | 核查 | 判据 |
|---|---|---|
| 1 | **元数据** | 标题 / 期刊 / 年 / 卷期页齐；缺的显式标注 |
| 2 | **数据真实性** | 每个数字**回原文对应语句**核过 |
| 3 | **一致性** | 篇数、作者-年份集合、数字，与证据表逐项一致 |
| 4 | **编号-引用双向** | 正文 `[n]` ↔ 文末编号表，**一一对应** |
| 5 | **语言层** | 引用自足、排他性断言有出处 |

> ⚠️ 「已核实」只证明**身份**（这篇文献确实存在），
> **不证明内容支持**（它确实支持你所引述的内容）。
