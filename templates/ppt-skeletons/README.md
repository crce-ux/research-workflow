## 二、规格（所有骨架共用）

> 🔴 **本表已于 2026-09-26 按 `ppt_style.py` 校正**——此前停在 2026-09-22 改版**前**
> （写主色 `#123E6B`、边距 40），与实际不符。**下方是转述，唯一出处是 `ppt_style.py`。**

| 项 | 值 | 出处 |
|---|---|---|
| 画布 | **1600 × 900** | `G["w"] / G["h"]` |
| 左右边距 | **61**（含虚线框，全元素统一）| `G["margin"]` |
| 标题栏 | 全宽主色色带，高 **72**（= 页高 8%）| `G["bar"]` |
| 主色 | **`#0046A4`** | `C["main"]` |
| 浅底（蓝调） | **`#E5EDF6`** | `C["tint"]` |
| 中性浅底 | `#F2F2F2` | `C["gray"]` |
| 可见边框 | `#D9D9D9` | `C["edge"]` |
| 强调 | `#C00000` | `C["red"]` |
| 正文 / 弱文字 / 页脚 / 细线 | `#333333` / `#7A8698` / `#9AA5B4` / `#E4E9EF` | `C["txt"]` 等 |

### 字号（已统一到 `ppt_style.py`）

**所有参数从 `_scripts/ppt_style.py` 派生，不要在本文件或脚本里手写数字。**

```
pt (文档口径)   88    73     36     24      19      14     30
px (SVG 口径)  147   122     60     40      32      23     50
级别          结尾页 封面  页面标题 章节小标题 正文  图注·页脚 大数字
```

> ⚠️ **`statement`（结尾页大标语）与 `cover`（封面）两档是 2026-09-22 补的**——
> 此前本表最大只到「封面 54pt / 90px」，**比模板少一档**（模板结尾页比封面还大）。
> 键名见 `ppt_style.PT`。

**依据**：画布 1600px = 13.333in = 960pt，**1 pt = 1.6667 px**。
| 口径 | 说明 |
|---|---|
| **pt** | 写进文档、跟 PowerPoint 对话时用 |
| **px** | SVG 里必须用这个 |

> ⚠️ **这是踩过的坑**：视觉规范 v2 §六 的字号表数字是 pt，但做 P05 样例时被当成 px 用了，
> **标题只有模板的一半**。现在由 `ppt_style.pt2px()` 自动换算，不会再错。
>
> 实测 6 份 deck 正文页标题字高（折算 1600 画布）：3深蓝白 71px ｜ 5绿 56–57px
> ｜ 4白蓝 57px ｜ 1深蓝 54px —— 对应本表的 `title = 60px`。

## 三、硬约束（来自 `汇报PPT产出流程手册 §四`）

1. **禁止 `python -c` 传参写 SVG** —— 中文会丢。用 Write 工具或本目录的生成脚本
2. 背景统一 `fill="#FFFFFF"`
3. 嵌入图片用 `<image href="…" preserveAspectRatio="xMidYMid meet"/>`，**相对路径**（`render_svg.py` 会自动绝对化）
4. 无图占位用虚线框（本库统一 `#7A8698` 虚线，**不用**手册 §四 里的 `#F0F4F8/#A0AEC0`——那两个色不在项目色板内，已记入待修清单）

## 四、重新生成 / 扩展

```bash
# 全部重生成（改了脚本里的尺寸或配色后）
python _scripts/make_svg_skeletons.py

# 渲染预览
python _scripts/render_svg.py <骨架>.svg 预览_<骨架>.png --scale 1
```

新增骨架 = 在 `make_svg_skeletons.py` 的 `BASES` 或 `VARIANTS` 里加一条，
然后跑生成 + 渲染 + 更新本 README 的两张表。
