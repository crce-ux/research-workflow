## ⭐⭐ 监管/政务数据库取数（2026-09-21 全面打通）

**根因**：**NMPA / 卫健委** 用 **瑞数信息（RiverSecurity）动态令牌**——HTTP 412，响应体为
`$_ts` + 混淆挑战脚本（`jsjiami.com.v6`）+ 指纹 JS。**CDE** 为纯 JS 渲染。

**❌ 已证伪（勿重复）**：curl/requests（412）· Playwright 无头（412）· Playwright 有头+stealth（412）·
goto→reload 换 Cookie（不过）· 反混淆 `api.js`（jsjiami+自定义 VM，不值得）

**✅ 基础方案：DrissionPage + 本机真实浏览器**

```bash
# 独立环境（注意：默认 python 是 hermes venv，**没有 pip**）
<本机解释器> -m venv dvenv
./dvenv/Scripts/python.exe -m pip install DrissionPage      # 4.1.1.4
```

```python
from DrissionPage import ChromiumPage, ChromiumOptions
co = ChromiumOptions()
co.set_browser_path(r"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe")
co.set_argument("--disable-blink-features=AutomationControlled")
page = ChromiumPage(co)
```

**原理**：DrissionPage 经 **CDP 接管真实浏览器进程**，不留 Playwright 自动化指纹。

**✅✅ NMPA 查批准文号：靠 localStorage 注入（关键发现）**

NMPA「数据查询」是 Vue SPA，**首页搜索框的触发事件驱动不了**（回车/点击均不发请求）。
但**结果页可独立访问**，且**搜索条件持久化在 localStorage** → 直接写入再访问结果页即可：

```python
URL = "https://www.nmpa.gov.cn/datasearch/search-result.html"
p.get(URL); p.wait(8)          # 先加载，否则 run_js 环境出错
# 境内生产药品：itemId=ff80808183cad75001840881f848179f，paraCode=item_2
# 境外生产药品：itemId=ff80808183cad7500184088665711800，paraCode=item_3
js = ("localStorage.setItem('searchkey','%s');"
      "localStorage.setItem('itemId','%s');localStorage.setItem('itemName','%s');"
      "localStorage.setItem('itemIdArray',JSON.stringify(['%s']));"
      "localStorage.setItem('selectValue',JSON.stringify([['%s','%s']]));"
      "localStorage.setItem('paraCode','%s');"
      "localStorage.setItem('searchRusultArray',JSON.stringify({code:200,data:[{itemId:'%s',"
      "name:'%s',itemDesc:null,nums:99}],message:null}));return 1;" % (...))
p.run_js(js); p.get(URL); p.wait(12)
```

- ⚠️ **表格异步渲染，`<table>` 解析常取到 0 行** → **改为对整页文本正则** `国药准字[A-Z]{0,2}\d+`，最稳
- 条目总数读页面文本 `共 N 条`（可确认查询确实执行）
- 字段：f0 批准文号 · f1 产品名称 · f3 商品名 · f5 规格 · f6 上市许可持有人 · f8 生产单位 · f9 批准日期
- **已交叉验证**：查得利拉鲁肽 `S20233109`/`S20233110` 与华东医药公告**逐字一致**

**✅ CDE 受理品种信息（稳定可用）**
- 入口 `https://www.cde.org.cn/main/xxgk/listpage/9f9c74c73e0f8f56a8bfbc646055026d`
- **UI 驱动**：输入药品名 → **按回车提交**（点"查询"按钮不触发）→ 读 `<table>` → 翻页 `.layui-laypage-next`
- ⚠️ 直接调 `POST /main/xxgk/getMenuListHc` **不可靠**（URL 带一次性令牌 `MmEwMD=...`，仅首次有效）
- 响应：`{"code":200,"data":{"records":[…]}}`（**键是 `records`**）
- 字段：`acceptid` 受理号 · `drgnamecn` 名称 · `companys` 申请人 · `applytype` 申请类型 · `registerkind` 注册分类 · `createdate` 承办日期

**✅ 国家医保局（nhsa.gov.cn，curl 直下即可）**
- 公告栏 `https://www.nhsa.gov.cn/col/col104/index.html`
- 目录附件 PDF：`/module/download/downfile.jsp?classid=0&filename=<hash>.pdf` → **PyMuPDF 解析后 grep 药名**
- 已验证：2025 版目录 202 页解析正常（**医保支付范围原文**可查，如"限成人 2 型糖尿病"）

**❌ 不可用**：`wbca.cde.org.cn`（CDE 上市药品信息 / 化学药品目录集）**需登录或法人实名认证**；**用户无账号**。

**ClinicalTrials.gov API v2**（直连无需浏览器）：
`https://clinicaltrials.gov/api/v2/studies?query.term=...`；过滤器 `filter.advanced=AREA[LeadSponsorClass]INDUSTRY`；
单条全量 `/api/v2/studies/<NCT>`（含 `eligibilityModule.eligibilityCriteria` 原文）

**⚠️ 重要教训：法定披露 ≠ 申报状态**
- 上市公司公告**存在滞后**；"某药是否已申报"**以 CDE 受理目录为第一手**
- 实例：甘李博凡格鲁肽（CDE 受理号 CXSS2600136-143，2026-09-02），当时公司尚未发公告 → 曾误判"媒体无据"
