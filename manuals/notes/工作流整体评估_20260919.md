## 二、⭐ 一个结构性缺口：**D 段之后是空白**

**「D 段之后是空白」是本次盘点最重要的发现。**

《全流程总纲》§二 一图，流程**止于**：

```
【D 课题设计（仅当目的是立项）】
  D1 子假设落地 → … → D5 伦理与数据管理
   │
  → 研究方案草案          ← 到这里就没了
```

**而实际科研还有大半段路**：

```
研究方案草案
   ↓
❓ 研究执行（入组、随访、数据采集）
❓ 数据管理（变量字典、清洗、质控）
❓ 统计分析（SAP 执行、结果解读）
❓ 论文撰写（结构、图表、投稿准备）
   ↓
✅ 投稿选刊（今日刚建）
   ↓
❓ 发表后（成果归档、履历更新）
```

**证据**：搜 `论文撰写流程 / 数据分析流程 / 结果报告流程` —— **零命中**。

> ⚠️ **也就是说：从"想清楚要做什么"到"做出来并写出来"这一段，目前没有流程。**
> 论文写作现靠 `paper-spine` 技能（**本库无对应文档**），
> 而数据与统计这一段**连技能都没有**。

## 三、三个具体缺口

### 缺口 1 · 统计分析：**只有"计划"，没有"执行"**

`课题设计流程手册` 里有 D2 样本量估算、D5 数据管理计划——
但它是**设计阶段写进方案的计划**。

**执行阶段**的以下几件事没有流程：

| 缺 | 说明 |
|---|---|
| 变量字典 / 数据字典 | 采集前定义每个字段的名称、类型、取值 |
| 数据采集与质控 | 入组表、随访表、缺失处理规则 |
| **SAP 执行与结果解读** | 计划定的分析，实际跑出来怎么读、怎么写 |
| 结果报告 | 从统计输出到图表到正文表述 |

> ⚠️ **风险**：D 段写的 SAP 如果执行时没对照，**方案与分析脱节**——
> 这种脱节正是预注册研究最常见的失分点。
>
> 本库有 `nature-statistics` 技能（统计方法审查），但**没有本库流程文档**。

### 缺口 2 · 论文撰写：**有技能，无文档**

| 有 | 缺 |
|---|---|
| `paper-spine` 技能（12 阶段编排）| 本库的**论文写作流程文档** |
| `nature-writing` / `nature-polishing` | IMRaD 结构规范、图表规范 |
| `academic-paper-reviewer`（投稿前自审）| **与本库核查方法的对接说明** |

> **不是从零建**——技能已在。缺的是**把它们串起来的文档**，
> 以及**与本库既有机制（核查方法/01、02、03）的接口**。

### 缺口 3 · 成果与发表管理：**完全没有**

搜 `成果清单 / 发表记录 / 学术履历` —— **只命中一份无关文档**。

**缺**：

- 发表记录（论文、会议、专利的持续台账）
- 成果归档规则（哪个项目产出了什么）
- **基金申报时的成果填报**（国自然要求列近五年主持/参加项目与代表性论文）

> ⚠️ **基金申报时的成果填报，与刚建的国自然板块直接相关**：
> NSFC 简历要求"如实标注本人署名情况（唯一第一作者 / 共同通讯等）"，
> **现在没有台账，到时候要回溯翻找**。

## 四、两处值得注意的比例

### 比例 1 · PPT 板块占 26%，是文献调研的 5 倍

| 板块 | 体量 | 占比 |
|---|---|---|
| **PPT / 汇报** | **123.2 KB**（8 份）| **26%** |
| 其他 / 调研记录 | 115.8 KB | 24% |
| 国自然+SCI | 72.7 KB | 15% |
| 核查方法 | 55.3 KB | 11% |
| 制度 / 索引 | 35.5 KB | 7% |
| 文本迭代 / 自检 | 33.3 KB | 7% |
| **文献调研** | **23.0 KB**（1 份）| 4% |
| **课题设计** | **11.8 KB**（1 份）| **2%** |

> **观察（不是结论）**：组会汇报是高频任务，投入多合理。
> 但**"课题设计"只有 2%**——而它决定了后面所有工作的方向。
>
> ⚠️ **待你判断**：上述板块占比，符合你的实际重心吗？

这些是**"研究怎么做研究"**，不是研究本身。

> **今天一天就产出了 6 份元工作文档**（约 90 KB）。

## 五、做得好的地方

| | |
|---|---|
| **三道硬门禁** | `check_assets` 五类自检，1–3 类硬门禁、4–5 类软检查——**有自动防腐机制** |
| **决策记录制度** | 7 条 ADR，含"推翻条件"。**今天已实证其价值**：0007 当天立、当天被自己的推翻条件触发而反转 |
| **单一出处纪律** | 总纲 §十 改指针、脚本总数唯一出处、术语表口径唯一——**主动防"内容有副本"** |
| **覆盖声明 / 停止纪律 / 隔离纪律** | 三条制度性纪律已入文档，**不是靠自觉** |
| **脚本化程度高** | 24 个脚本承担机械劳动——**token 省在该省的地方** |

## 六、建议（按性价比，**不代替你决定优先级**）

| # | 建议 | 理由 | 成本 |
|---|---|---|---|
| **1** | **补《数据与统计分析流程》** | 缺口 1——D 段的 SAP 到结果之间是断的，且**无技能兜底** | 中 |
| **2** | **建成果台账**（一份持续维护的表） | 缺口 3——**与国自然板块直接相关**，越晚建越难回溯 | **低** |
| **3** | **补《论文撰写流程》**（串 `paper-spine` + 核查方法） | 缺口 2——技能已在，缺串联与接口 | 中 |
| **4** | 总纲 §二 一图**延长到 D 段之后** | 结构缺口——图停在"方案"会让人以为流程到头了 | **低** |
| **5** | P 段补独立手册 | 其余四段都有，P 段只有索引里的一个小节 | 低 |

> ⚠️ **第 2 项成本最低、时效性最强**——NSFC 简历要求列近五年成果，
> **现在不建，两年后要翻五个项目的归档**。

## 七、一句话

> **前端（查文献 → 出汇报）已经相当成熟，后端（做研究 → 出论文）基本空白。**
> 而 D 段之后的空白，恰好是你**真正要做研究时会走的路**。
