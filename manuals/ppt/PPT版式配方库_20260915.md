# PPT 版式配方库（v2）

> **与《视觉规范 v2》的分工**：
> - 视觉规范 = **语言**（配色、区块 A、骨架 B、连接件 C 的清单）
> - 本文件 = **短语**（把 A/B/C 组合成具体版式，附出处与适用场景）
>
> **用法**：设计一页时，先在本文件找**最接近的配方**，再按 §附录 A 定位自己的页。

图例：`A?` 区块类型 ｜ `B?` 分区骨架 ｜ `C?` 连接件 —— 均见视觉规范 v2

## 受众速查（选择入口）

> **⭐ 2026-09-26 新增。** 本库原先只有**版式**一个轴（要放什么 → 用哪个配方）。
> 但同一套版式，**受众不同，内容取舍完全不同**——
> 为专家准备的汇报，**删掉他的常识，留给他新信息**。
> 故补此轴：**先按受众定取舍，再按版式选配方。**

| 受众 | 他已经知道 | 该删 | 该留 | 高频起点 |
|---|---|---|---|---|
| **导师**（最懂本课题） | 课题全貌、方法、既往结果 | 课题背景、方法原理 | 新数据、新证据、**待决问题** | 17 数据卡片 · 30 带表头小卡片 · 12 左右双栏对照 |
| **同领域研究者**（懂领域、不懂本课题） | 领域常识、通用方法 | 教科书级背景 | **缺口在哪、证据链怎么走** | 1 章节过渡页 · 28 结论色带→箭头→结论色带 · 9 并列→汇聚 |
| **跨领域听众** | 只有大概念 | 领域术语、方法细节 | **结构、逻辑、类比** | **32 目录页** · 10 三栏等宽+色带表头 · 13 2×2 浅底方块网格 · 15 横向胶囊流程条 |
| **开题 / 答辩评委** | 领域与方法 | 已发表的常规结果 | **可行性、创新点、风险** | **32 目录页** · 12 左右双栏对照（已完成↔拟开展）· 24 旗标斜切通栏声明 · 31 结尾页大标语 |
| **文献汇报**（单篇精读） | 不一定读过该文 | 与课题主线无关的分支 | **方法、主要结果、与课题的关系** | 2 左框→箭头→右图 · 18 数据库截图+大数字 · 26 压图标签 |

**用法**：上表定位受众 → 定「该删 / 该留」→ 再往下按版式选具体配方。

> ⚠️ **末列只是"高频起点"，不是推荐排序、也不代表优先级**——
> 具体用哪个，按**你这一页实际要放什么**来定（见 §一 起各配方的「适用场景」）。

> ⚠️ **待人工复核**：本轴依《PPT工具链手册》的「受众定位决定详略」原则补入，
> **尚未经实战校准**。用过两三次后回来修。

## 〇、固定件（几乎每页都有，不编号）

这四件是**"系统感"的来源**——每页都有、位置固定、样式统一。缺了它们，单页再漂亮也不像一份材料。

### 0.1 标题区 · **色带版**（7 套中 6 套采用）

```
┌──────────────────────────────────────┐
│ ▌01  屏状核：位置、体积与连接          │  A1 全宽主色色带，高 = 页高 8%
└──────────────────────────────────────┘
```
- 白字左对齐，可带编号 `01` / `|1.1`
- 实测采用率：1深蓝 8/17、2亮蓝 12/17、3深蓝白 11/19、4白蓝 11/17、5绿 12/17、**6红 0/19**、7紫 12/17

### 0.2 标题区 · **双横线版**（无标题带时的替代）

```
──────────────────────────────────────
        一、立项依据与研究现状              ← 主色字 + 居中
──────────────────────────────────────
```
- **6红色系 19 页全部采用此方案**——这是"不画色带也能有系统感"的唯一答案
- 标题**上下各一条细横线**，标题用主色字、居中

### 0.3 导语条（标题下方一句话）

- 位置固定在标题区正下方，**跨全宽**
- 一句话概括本页论点，**关键词用强调色**
- 实测：1深蓝、2亮蓝、3深蓝白、5绿、6红 —— **5 套采用**

### 0.4 章节编码标题

- 形如 `1.2.3 选题研究意义` / `2.1 主要创新点`
- **让读者随时知道"我在整个报告的第几层"**
- 实测：4白蓝、5绿 —— 2 套

## 一、章节过渡

### 配方 1｜⭐ 章节过渡页（提纲重播 + 当前位置高亮）
**出处**：**6 份 deck 全部采用**（6/6），最高频元素

```
┌──────┬─────────────────────────┐
│      │  01  立项背景和研究思路   │ ← 当前：主色底白字 / 大号
│ 汇报 │  02  创新点和主要技术内容 │ ← 其他：灰字
│ 答辩 │  03  应用推广和经济社会效益│
└──────┴─────────────────────────┘
  A2 竖排色块        A1 高亮块
```
- **骨架** B5 ｜ **左** A2 竖排章节名 ｜ **右** 提纲列表
- **关键**：**每次过场都重播整份提纲**，只把当前位置点亮 —— 读者永远知道进度
- **实测频次**：3深蓝白 7 次、6红 6 次、其余 4–5 次
- **适合**：任何 ≥10 页的汇报。**本项目 18 页强烈建议加**

### 配方 32｜⭐ 目录页（开篇一次性总览）
**出处**：**自建**（2026-09-26 补缺）——7 套模板与**此前全部配方都没有这一页**

```
┌──────┬──────────────────────────────────────┐
│      │ [01] 研究背景与立论依据 ──────── 03 │
│      │      问题从哪来、为什么值得做         │
│ 目   │ ──────────────────────────────────── │
│      │ [02] 证据基础与检索口径 ──────── 07 │
│ 录   │      查了什么、查到什么、边界在哪     │
└──────┴──────────────────────────────────────┘
  A2 竖排色块     序号方块 + 章节名 + 一句话 + 引线 + 页码
```

- **骨架** `配方32_目录页.svg`
- **与配方 1 的分工**（**别混用**）：

  | | 配方 1 章节过渡页 | **配方 32 目录页** |
  |---|---|---|
  | 出现次数 | **每个章节前各一次** | **全篇一次**（开篇） |
  | 做什么 | **重播**整份提纲 + 高亮**当前位置** | **总览**全部章节，无当前位置 |
  | 读者得到 | 「我在第几部分」 | 「这份汇报要讲哪几件事」 |

- **适合**：≥3 个章节、且听众**不熟悉**汇报结构的场合（开题/答辩/跨领域汇报）。
  **若通篇已用配方 1 逐章重播，可不再单设目录页**——两者信息重复。
- **⚠️ 页码是示例值**（03/07/12/16），复制后**必须按实际页序改**
- **设计约束（有意为之，勿误改）**：
  - 章节名用 `main`（8.71:1）、说明用 `txt`（12.63:1）——**不用 `weak`**：
    `weak #7A8698` 在白底仅 3.69:1，`ppt_check` 第 J 项会报
  - 层次靠**字号 40/23 + 颜色 main/txt**，**不靠字重**（PPTX 端字重只有 2 档）
  - 引线**从章节名实测宽度起算**，不写死——标题不等长，起点本就该不同（TOC 惯例）

## 二、图文衔接

### 配方 2｜左框 →箭头→ 右图
**出处**：3深蓝白「拟解决的问题」

```
┌────────────┐          ┌──────────┐
│ 文字/要点框 │──C1箭头─▶│   图      │
└────────────┘          └──────────┘
```
- **骨架** B2 两栏 ｜ **组成** A6 虚线框 + **C1 横箭头** + 图（无边框）
- **关键**：箭头端点**咬在框边**（不是悬空）；图紧贴它所支持的那一条
- **判据（删图测试）**：删掉这张图，旁边那段话**说不通** → 是论据；照样通 → 是装饰

### 配方 3｜图下统一彩色标签
**出处**：2亮蓝（≡7紫）、4白蓝、5绿 —— **3 份 deck 采用**

```
┌────────┐  ┌────────┐  ┌────────┐
│  图1   │  │  图2   │  │  图3   │
└────────┘  └────────┘  └────────┘
 ▌标签一     ▌标签二     ▌标签三        ← 主色小标签，宽度只包住文字
```
- **A8 压图标签**的"页级统一版"：**同一页所有图用同一位置、同一配色、同一字号**
- **标签色 = 本模板主色**（绿模板用绿、紫模板用紫）
- **价值**：把图组从"一堆图"变成"一组有名字的证据"

## 三、表格

> ⚠️ **7 套模板合计只有 5 个表格**，但**本项目 18 页有 7 页是纯表格**。
> 这一族是**两边语言差距最大的地方**，优先看。

### 配方 4｜表格 + 引出线标注
**出处**：6红「项目创新」

```
┌──────────────────────┐   ┌─标注框─┐
│ Photal │ E(EV)│ …    │◀──│ 光催化 │
│ TiO     │ 3.0  │      │ C5│  产氢  │
│ ZnS     │ 3.7  │      │◀──└────────┘
└──────────────────────┘   └─CH4氧化┘
   红字 = 被标注的那一格
```
- **骨架** B1 通栏表 ｜ **组成** A1 深蓝表头 + 隔行浅底 + **A5 标注框** + **C5 引出线**
- **关键**：引出线落在**具体单元格边界**，不是表格外框
- **双重编码**：被标注单元格的文字**同时变红**
- **适合**：数据表要指出**某一行/某一格**

### 配方 5｜表格 + 右侧配图
**出处**：3深蓝白「国家需求」、4白蓝「现状与趋势」—— **2 套**

```
┌─────────────────────┐  ┌────┐┌────┐
│ 表头 │   │   │   │  │  │ 图1││ 图2│
│──────┼───┼───┼───│  │  └────┘└────┘
│      │   │   │   │  │  ┌────┐
│      │   │   │   │  │  │ 图3│
└─────────────────────┘  └────┘
```
- **关键**：**表格与图各占一半宽度**，表格给"事实"，图给"样子"
- **适合**：表格内容有实物对应（政策文件、设备、样本、图谱）

### 配方 6｜表格 + 底部结论色带
**出处**：6红「预期成果与风险分析」

```
┌───────────────────────────┐
│ 类别 │ 说明 │ 涉及程度 │等级│
│      │      │ ▣涉密一  │ 低 │ ← 单元格内彩色小标签
├───────────────────────────┤
│ ▌ 提前预警、组织高效、风险可控 │ ← A1 通栏结论色带
└───────────────────────────┘
```
- **组成** 表 + **单元格内彩色小标签**（A5 的迷你版）+ **A1 底部通栏**
- **价值**：**给表格一个结论**。纯表最缺的就是"所以呢"

### 配方 7｜细竖线分栏（保持整体感）
**出处**：6红「立项依据·市场预测」

```
┌────────────────────────────────┐
│  块①   │   块②    │   块③     │
│        │          │           │   ← 大白框 + 细竖线
└────────────────────────────────┘
```
- **与三张独立卡片的区别**：**一个整体**，不是三个并列物
- **适合**：三块内容相关、想强调"同属一件事"

## 四、并列与汇聚

### 配方 8｜标签 →箭头→ 说明（三元组）
**出处**：7紫「国家重大需求」、3深蓝白「拟解决的问题」

```
┌───┐          ┌────────────────────┐
│标签│───C1───▶│ 说明文字，末尾红字  │
└───┘          └────────────────────┘
```
- **骨架** B6 上下两段（常两个三元组**并排**）
- **关键**：箭头把"**因为 A 所以 B**"显式化
- **适合**：**两组对照概念**（人工智能 / 高速电路；说法 / 反证）

### 配方 9｜并列 → 汇聚（多上游到一个下游）
**出处**：7紫「国家重大需求」右栏

```
┌────┐ ┌────┐ ┌────┐
│细胞A│ │细胞B│ │细胞C│
└────┘ └────┘ └────┘
    └──── C1 竖箭头 ────┘
           ▼
   ┌────────────────┐
   │ 神经节细胞（结果）│  ← A1 加重
   └────────────────┘
```
- **关键**：上游**横排** = 同层级并列；箭头 = 汇聚；下游用**实心色块加重**
- **适合**：**多个因素共同导致一个结果**——本项目最值钱的一个配方

### 配方 10｜三栏等宽 + 色带表头 + 递进线
**出处**：7紫「忆组类脑」、3深蓝白「拟获得成果」、5绿「国家重大需求」

```
┌─表头A─┐ ┌─表头B─┐ ┌─表头C─┐
│ 机制  │ │ 理论  │ │ 应用  │   ← 左→中→右 是一条递进线
│ ┌───┐ │ │ ┌───┐ │ │ ┌───┐ │
│ │A5 │ │ │ │A5 │ │ │ │A5 │ │
│ └───┘ │ │ └───┘ │ │ └───┘ │
└───────┘ └───────┘ └───────┘
```
- **骨架** B3 ｜ **每栏** A1 表头 + A5 重点块
- **关键**：三栏要有**递进关系**，不是随便三块
- **收口**：底部常配一句红字结论（3深蓝白 P11）

### 配方 11｜加号串联（A ＋ B ＋ C）
**出处**：5绿「1.5 研究问题及目标解决」

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ 基因型与  │  +   │ 根系水分  │  +   │ 分泌物与  │
│ 抗旱性   │      │ 导度     │      │ 微生物   │
└──────────┘      └──────────┘      └──────────┘
```
- **骨架** B7 ｜ **连接件 C3 加号**
- **关键**：**叠加 / 共同作用，不是因果**。多因素同时起作用时用箭头就错了

### 配方 12｜左右双栏对照（已完成 ↔ 拟开展）
**出处**：4白蓝「研究内容及科学问题」

```
┌─已完成问题─┐   ┌─拟展开问题─┐
│ ┌─表头─┐  │   │ ┌─表头─┐  │
│ │ 三栏 │  │   │ │ 三栏 │  │
│ └──────┘  │   │ └──────┘  │
└───────────┘   └───────────┘
```
- **关键**：两栏**结构完全对称**，只换内容 —— 差异自己跳出来
- **适合**：**对照关系**（说法 ↔ 反证、两派 ↔ 依据、现状 ↔ 目标）

### 配方 13｜2×2 浅底方块网格
**出处**：6红「三种干细胞」
- **骨架** B8 田字格 ｜ **组成** A5 浅底块 ×4
- **适合**：四条**并列属性**（低免疫原性 / 多功能分化潜能 / 自我更新 / 良好组织相容性）

## 六、数据展示

### 配方 17｜⭐ 数据卡片
**出处**：**6 份 deck 全部采用**（1深蓝、2亮蓝≡7紫 P06/P12/P16、4白蓝 P16、5绿 P10/P13、6红 P14）

```
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│  10⁹×    │ │  115 fJ  │ │  85 ps   │ │  10¹²×   │
│  开关比   │ │  开关能耗 │ │ 开关速度  │ │ 擦写次数  │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
   浅底 + 主色细边框；大号彩色数值 + 小号深灰标签
```
- **组成** A5 浅底块 ｜ **数值**用主色或强调色、**字号约正文 1.6 倍** ｜ **标签**深灰小字

### 配方 30｜带表头小卡片 ⭐
**出处**：5绿「1.1 / 1.2 / 2.1」、3深蓝白「国家需求」—— **内容区的主力形态**

```
┌─ 深色小表头 ──────┐   ┌─ 深色小表头 ──────┐
├───────────────────┤   ├───────────────────┤
│ 内容行            │   │ 内容行            │
│ 内容行            │   │ 内容行            │
└───────────────────┘   └───────────────────┘
        ↕ 卡片间距（约 32）      ↕
```

- **关键**：**把「一个大表格」拆成 2–4 块**，每块 = 表头 + 白底内容 + 细边框 + 卡片间距
- **⚠️ 不要拿它拼回一个整表** —— 它的价值就在**拆**。这是模板与「一个表格到底」的核心差别
- **用法**：`ppt_kit.cards_row(y, h, [(标题, [行…]), …])`（等宽等距自动排）

> **⭐ 为什么它重要（2026-09-22 实测）**：
> 7 套模板里 **6 套**的图片有 **71–85% 是面积 <3% 的小件**（图标 / 编号 / 色点 / 装饰线）。
> 模板的「丰富」来自**元素密度**，不来自大图。拆卡片正是把元素数提上去的最直接手段。

## 附录 C：六个"不要"

**版式层**

1. **不要图片墙** —— 图集中放一侧 = 装饰。过**删图测试**
2. **不要小字图** —— 图内字缩到幻灯片上 < 9px = 无效（判据 C）
3. **不要用错连接件** —— 叠加用 `+`，因果用 `→`，对比用 `≠`
4. **不要整句变红** —— 红只点**关键词和数字**

**方法层（2026-09-15 扫描新踩的坑）**

5. **不要把同一份 deck 当两个样本** —— 实测「2亮蓝白色系」与「7紫色系」17/17 页指纹完全相同，是同一 deck 换配色。
   把它们当两个独立证据，会让"跨 deck 复现"这条判据失效，配方频率虚高。
   **计数单位是 deck（6），不是文件数（7）。**
6. **不要用页实例数冒充设计多样性** —— 章节过渡页共 **25 个实例**，但只对应 **6 个设计**（每 deck 一个）。
   记作「1 配方 + 6 变体」，既不记 25，也不记 6。
