## 〇、怎么用这份规范

> **配套文件**：`PPT版式配方库_20260915.md` —— 本文件定义**语言**（A/B/C 清单），
> 配方库提供**短语**（把 A/B/C 组合成 **32 个**具体版式 + 本项目 18 页映射）。
> **实际设计时先翻配方库找最接近的一页，再回本文件查参数。**

**不要去找"版式原型"。** 版面是三层**组合**出来的：

```
版面  =  分区结构（B）  ×  区块类型（A）  ×  连接件（C）  ＋  标注层（§五）
```

**设计一页的四步**：

```
① 选骨架     → §三 挑一个 B（8 种）
② 每格选区块 → §二 挑 A（8 种）
③ 连起来     → §四 挑 C（7 种）
④ 要不要标注 → §五 决定是否加标注层
```

> 组合数是**乘出来**的，不是数出来的。新页面按需组合即可。

## 二、库 A：区块类型（8 种）

| # | 区块 | 底 | 边框 | 字 | 用于 |
|---|---|---|---|---|---|
| **A1** | 横色带表头 | 实心主色 | 无 | 白 | 卡片/栏目顶或**底** |
| **A2** | 竖色带标签 | 实心主色 | 无 | 白（竖排） | 页面左右边缘、栏目标签 |
| **A3** | 旗标斜切块 | 实心主色 | 无 | 白 | 单条通栏声明（右端斜切） |
| **A4** | 编号块 | 实心主色 | 无 | 白 | `01/02/03`，直角或胶囊 |
| **A5** | ⭐ **浅底强调块** | **`#E5EDF6`** | **`#C00000` 或主色细线** | 深灰/红 | **关键数值、要点句、公式** |
| **A6** | 虚线框 | 白/浅 | 主色虚线 | 深灰 | 圈一组相关项 |
| **A7** | 胶囊节点 | 实心主色 或 白 | — | 白/主色 | 流程中间节点（研究目标/实验证实） |
| **A8** | 压图标签 | 主色 或 红 | 无 | 白 | 压在图上 |

### 🔴 v1 错误修正 ②

> v1 写「**全部实心填充主色 + 白字——不用浅灰底**」——**不完整**。
>
> **浅底 + 强调色边框**（A5）是模板里**最常用的内容重点块**，
> 与"结构性区块"（A1–A4）是**两套不同语言**，v1 把两者混为一谈了。

**正确的二分**：

| 类别 | 样式 | 用在哪 |
|---|---|---|
| **结构性**（A1–A4） | 实心主色 + 白字 | 表头、编号、分区标签 |
| **内容性**（A5） | **浅色底 + 强调色细框** | 关键数值、要点句、公式 |

### 🔴 v1 错误修正 ③

> v1 写「**全部是直角（或纯圆）——不用圆角矩形**」——**太绝对**。

**形状实测**（7 套模板 `prstGeom` 统计，共 2520 个）：

```
rect        ×1453  (57%)      ← 表格单元格为主
roundRect   ×616   (24%)      ← 圆角矩形，大量使用
line        ×163
homePlate   ×51               ← 旗标（A3）
parallelogram ×42             ← 平行四边形
round2SameRect ×38            ← 胶囊
ellipse     ×33
downArrow   ×29
chevron     ×19
```

**正确规则**：

| 类别 | 形状 |
|---|---|
| **结构件**（表头 / 编号块 / 分区标签） | **直角** |
| **节点 / 小标签**（研究目标、实验证实） | **可以是圆角或胶囊** |
| **旗标声明** | `homePlate` 斜切 |

## 四、库 C：连接件（7 种）

| # | 件 | 表达 | 备注 |
|---|---|---|---|
| **C1** | 横箭头 `→` | **因果 / 流向** | |
| **C2** | 竖箭头 `↓↑` | **状态变化 / 递进** | 与 C1 分工：**横 = 流向，竖 = 变化** |
| **C3** | 加号 `+` | ⭐ **叠加 / 共同作用** | **不是因果！**多因素同时起作用时用箭头就错了 |
| **C4** | 等号 `=` / `≠` | 对比 | |
| **C5** | 引出线 | 从标注连到**具体单元格/数据点** | **红 = 论点强调；黑 = 中性技术标注** |
| **C6** | 花括号 `}` | 分组 | 常配 A7 胶囊节点 |
| **C7** | ⭐ **带语义标签的箭头** | **把关系写出来** | 「技术支撑」「结果辅导」 |

> **C7 最容易被忽略**：箭头旁边写清楚它代表什么关系，读者不用猜。
> 例：`组织学 2.5cm³  ≠  在体 MRI 3.3cm³`，光是 `≠` 不够，
> 要在旁边写「**方法差异**」——表达才完整。

## 五、标注层：把图变成证据

### 5.1 ⭐ 数据库截图 + 红框 + 大数字

把 **PubMed / ClinicalTrials.gov / 协议注册库**的检索界面**直接截图**放上去：

- **红框**圈出关键区域
- 旁边压**红色大数字**
- **红箭头**从数字指向截图上的点

**作用**：把"我确实查过"从**口头声明**升级为**一手证据**。

> **本项目最该用这招的地方**：P17「交叉空白的规模」——
> 把零证据复核的分层检索结果截图，红框圈命中数，压上 `0 / 1`。
> 比任何文字描述都有说服力。

### 5.2 压图标签 / 标注框
主色或红色小标签**压在图上**（A8）。

### 5.3 ⭐ 图片墙 vs 图文衔接

| | 做法 | 结果 |
|---|---|---|
| ❌ **图片墙** | 图集中成网格放一侧 | 图与文无对应，是**装饰** |
| ✅ **图文衔接** | 图紧贴它要证明的**结论** | 图是**论据** |

**判据（删图测试）**：

> 把某张图删掉，它旁边的文字是否**说不通**？
> **说不通 = 论据；照样通 = 装饰。**

### 5.4 图注
统一颜色（本项目用 `#C00000`）、统一位置（图正下方）、统一字号（14–16）。**全 deck 二选一，不要混。**

### 6.1 ⚠️ 字号：**单位是 pt，不是 px**

> **这是踩过的坑**：早期做 P05 样例时把下表的数字当成 px 直接写进 SVG，
> 结果标题**只有模板的一半大**。
>
> 换算：画布 1600px = 13.333in = **960pt** ⟹ **1 pt = 1.6667 px**
> （`ppt_style.pt2px()` 自动算，不要手换算）

| 级别 | **pt**（文档口径） | **px**（写进 SVG） | 用途 | 模板实测字高* |
|---|---|---|---|---|
| 结尾大标语 | ⭐ 88 | **147** | 结尾页 | **模板比封面还大**（117@1280 > 97@1280） |
| 封面主标题 | 73 | **122** | 封面 | 66–88pt |
| **页面标题** | **36** | **60** | 标题栏内 | ≈36pt（字高 54–71px） |
| 章节小标题 | 24 | **40** | 内容区小节 / 卡片标题 | 28pt |
| **正文** | **19** | **32** | 正文 | 20–24pt |
| 大数字 | 30 | **50** | 数据卡片 | 24–28pt |
| 图注 / 页脚 | 14 | **23** | 图上标签 / 出处 / 页码 | 14–16pt |

\* 实测自 6 份 deck 正文页（2026-09-15）。

**两条反直觉的**：

- **大数字只有 24–30pt**——和章节标题同级。它靠**颜色 + 字重 + 孤立**抓眼，**不是靠尺寸**。
  把它做到正文的 3 倍反而会失控。
- 页面标题模板实测约 **36pt**，比本文档早期写的「30–32」高一档。

### 6.2 字号层级（速查）

```
结尾标语 147px ｜ 封面 122px ｜ 页面标题 60px ｜ 章节小标题 40px ｜ 正文 32px ｜ 大数字 50px ｜ 图注·页脚 23px
```

## 七、⚠️ 反面教材：图内文字不可读

**判据 C**（来自 `汇报PPT产出流程手册 §3.0`）：

```
幻灯片上字号 = 图内字号 × 幻灯片显示宽 ÷ 原图宽
< 9px  →  不可读，图作废
```

### 实测：国自然模板自己也翻车

| 页 | 图内字缩到幻灯片上 | 判定 |
|---|---|---|
| 「国家重大需求」LGN 分区表 | ≈ **2.8px** | ❌ 纯装饰 |
| 「忆组类脑」SNN 示意图 | ≈ **5–7px** | ❌ 但有表头兜底 |

> **救不回来的判据**：图内文字不可读时，**必须靠外部色带表头把语义补回来**。
> 第一例之所以彻底失效，就是因为**它外面什么标注都没有**。

**推论**：图片墙 + 小字 = 无效。**宁可少放图，也不要放读不出的图。**
