# 全 7 套 · 终版结论

## 〇、过程中的两次自我推翻

> 本结论是**改了三次**才定的。记下来，因为它本身就是方法学教训。

| 轮次 | 我当时说的 | 后来怎么发现错的 |
|---|---|---|
| **第 1 轮**（1 套） | "缺口 1 是图片密度，要铺开到 1.5–2 张/页" | 看面积分布——76% 是 <3% 的小图，**不是内容图** |
| **第 2 轮**（3 套） | "边距 4.7%、标题栏 10.7% 是共性，要改" | 跑满 7 套——**实测 3.1–7.9%，标题栏 3 套有无不一** |
| **第 3 轮**（7 套） | "装饰件占多数是最强共性（81–85%）" | **指标被污染**——2亮蓝白/7紫 每页有整页背景图，把分母撑大了 |
| **终版** | 见下 | **排除整页背景图后重算**：6/7 套装饰件占 **71–85%** |

**教训**：`pptx_to_svg` 给的是结构数据，但**"这个数字算不算数"仍需人工判断**。
两次错误的共同点——**我拿一个未验证的指标去下结论，而不是先问"这个指标的定义对吗"**。

## 二、❌ 撤回的三项

### 2.1 "边距 4.7%" → 改成 **3.8%**（方向对，数值错）

7 套实测：3.1 / 3.8 / 3.8 / 3.8 / 4.7 / 4.9 / 7.9 %

- **中位 = 3.8%**，5/7 落在 3.1–4.9%
- **我们现用 2.5%——低于全部 7 套的下限**

> ✅ **方向是对的（我们确实太挤），但 4.7% 是单套值。**
> **正确目标 = 3.8% × 1600 = 61px**（不是此前说的 76px）。

### 2.2 "标题栏 72 → 96px" → **撤回**

| 套 | 内容页顶部 |
|---|---|
| 3深蓝白色系 | ✅ 有通栏标题带 |
| 5绿色系 | ❌ 「章节号 + 标题」+ 绿竖条 |
| 6红色系 | ❌ 「红字标题 + 横线」 |

**3 套里 2 套没有标题带**，且与配方库旧记录「6红色系 标题带采用率 **0/19**」吻合。

### 2.3 "封面/结尾各 1 张整页背景" → **撤回**

| 套 | 整页背景图 |
|---|---|
| 1深蓝色系 | 2 张（封面 + 结尾） |
| **2亮蓝白 / 7紫** | **22 张（每页都有）** |
| **3深蓝白 / 4白蓝 / 5绿 / 6红** | **0 张** |

**三种做法都有，不构成共性。**

## 三、⭐ 最关键的两项（视觉核实所得）

### 3.1 内容区是「卡片系统」，不是「大表格」

**5绿色系** 的内容页是：

```
┌─ 深色小表头 ────────┐   ┌─ 深色小表头 ────────┐
├─────────────────────┤   ├─────────────────────┤
│ （白底 · 内容行）    │   │ （白底 · 内容行）    │
└─────────────────────┘   └─────────────────────┘
        ↕ 卡片间距                ↕
```

**一页 2–4 个卡片**，每个 = 表头 + 内容 + 边框 + 间距。

> **我们的表格页 = 一个表格；模板的同类页 = 3 个带表头的卡片。**
> **元素数量差在卡片数量上，不在图片。**

### 3.2 装饰件才是密度来源

排除整页背景后，**6/7 套的图片里 71–85% 是 <3% 面积的小件**——
编号角标、色点、装饰线、小图标。**它们不传递信息，只提供细节感。**

## 六、转换能力的最终边界

| 能提取 | 不能提取 |
|---|---|
| ✅ 边距 / 栅格 / 对齐线（坐标精确） | ❌ **阴影**（`outerShdw` 丢失） |
| ✅ 字号 / 字重 / 字体族 / 对齐 | ❌ 斜向渐变填充 |
| ✅ 母版 / 版式 / 页 **三层结构** | ❌ 动画与转场 |
| ✅ 每个装饰件的形状与几何 | ❌ 字体本身（需系统已装） |
| ✅ 图片尺寸与位置（**需区分背景图与装饰件**） | |
| ✅ 调色板与用量占比 | |

> ⚠️ **指标必须人工验证定义**——本次两个错误（小图占比、顶部带）都源于此。
> **异常值（如 166.8%）是"定义有问题"的信号，不是发现。**
