# 跨模板验证：哪些能改，哪些不能

## 〇、一句话

> **"小图密度"和"字重体系"是真共性，可以放心改；**
> **"边距 4.7%"和"标题栏 10.7%"是 3深蓝 色系单独的特点，不该照搬。**
> 视觉核实还发现了一件前两篇都没看到的事——**模板的内容区是"卡片系统"**。

## 三、❌ 证伪的两项（不该照搬）

### 3.1 边距 4.7% —— 不是通则

| 套 | 左边距 | 占画布 |
|---|---|---|
| 5绿色系 | 48 px | **3.8%** |
| 3深蓝白色系 | 61 px | **4.7%** |
| **6红色系** | **102 px** | **7.9%** |

**跨套差 2 倍。** 所以"模板边距 4.7% → 我们该改成 76px"**没有依据**——
它只是 3深蓝 这一套的数。

> ⚠️ 前篇把它写成了通则，**此处更正**。

### 3.2 标题栏 10.7% —— 更不是通则

**脚本检测不可靠**：红色系测出 166.8%（超过页高），是把**封面整页红底**误判成了顶部带。

**原生视觉逐套核实后，真实情况是：**

| 套 | 内容页顶部结构 |
|---|---|
| 3深蓝白色系 | ✅ **有通栏标题带**（蓝色渐变带，内含编号 + 标题） |
| **5绿色系** | ❌ **无通栏带**——是「**章节号 + 标题**」文字（如 `1.1 国家重大需求`）+ 左侧绿色竖条 |
| **6红色系** | ❌ **无通栏带**——是「**红字标题 + 横线**」 |

**3 套里 2 套没有标题带。**

> ⚠️ 前篇建议"标题栏 72 → 96px"，**依据不成立**——它同样是 3深蓝 一套的特点。
> 而且这与配方库早先记录的「6红色系 标题带采用率 **0/19**」**完全吻合**。

## 四、⭐ 视觉核实看到的、脚本没测出来的东西

### 三套的**内容区语言完全不同**

| 套 | 内容区构成 |
|---|---|
| 3深蓝白色系 | 图片带 + 色带小标题 + 表格 |
| **5绿色系** | ⭐ **卡片系统**——**绿底小表头 + 白底内容 + 细边框 + 卡片间距** |
| 6红色系 | 红字标题 + 横线 + 大量留白 + 竖条过渡页 |

### ⭐ 5绿色系的「卡片系统」——"元素密度"的具体做法

看 `5绿色系` 的内容页（P03/P04/P05/P10/P11/P12/P13）：

```
┌─ 绿底小表头 ─────────┐   ┌─ 绿底小表头 ─────────┐
│ 鼓励农业创新…        │   │ 农业科技创所…        │
├──────────────────────┤   ├──────────────────────┤
│ （白底 · 内容行）     │   │ （白底 · 内容行）     │
│                      │   │                      │
└──────────────────────┘   └──────────────────────┘
        ↕ 卡片间距                  ↕
```

**关键特征**：
1. **每个卡片 = 深色小表头 + 白底内容**（不是我们的"一个大表格"）
2. **卡片有可见边框**（细线）
3. **卡片之间有间距**（不是紧贴）
4. **一页 2–4 个卡片**，每个卡片自成一块

> **这直接对应"缺口 2（浅底色块）"**——但实现方式不是"加浅底色块"，
> 而是 **"把内容拆成带表头的小卡片"**。
>
> **我们的表格页 = 一个表格；模板的同类页 = 3 个带表头的卡片。**
> 元素数量差在这里，不在图片。

### 过渡页：三套各不相同

| 套 | 过渡页形式 |
|---|---|
| 3深蓝白色系 | （不明显） |
| 5绿色系 | 白底 + **绿色竖条** + 编号列表 |
| **6红色系** | **红色竖条色块**（占左侧约 1/5）+ 编号列表 |

→ **过渡页是各套差异最大的地方**，不宜统一。

## 六、方法学备注：脚本指标的可靠性

| 指标 | 可靠性 |
|---|---|
| 边距（文字 min x） | 🟢 可靠 |
| 图片尺寸/面积占比 | 🟢 可靠 |
| 字体族 / 字号分布 | 🟢 可靠（直接读属性） |
| **"顶部通栏带"** | 🔴 **不可靠**——会把整页色域误判为顶部带。**必须目视复核** |

> **教训**：`pptx_to_svg` 给的是**结构数据**，但"这是什么"仍需人（或视觉）判断。
> **脚本测出的异常值（如 166.8%）本身就是信号——它说明指标定义有问题，不是发现。**
