### 🔴 维普的四个坑（全部实测复现）

| # | 坑 | 表现 |
|---|---|---|
| ① | **裸词静默失效** | `key=屏状核`（无字段前缀）→ 返回**与检索词完全无关的通用最新列表**，不报错。实测：裸词 0 篇相关；`U=屏状核` 124 篇；`M=屏状核` **31 篇** |
| ② | **检索式含空格 → WAF 403** | `M=(屏状核) AND M=(氯氮平)` → 403 Forbidden |
| ③ | ⚠️ **布尔式解析错误 → 静默假阳性**（最危险） | 去空格后 `M=(屏状核)AND M=(氯氮平)` 通过，命中 3 条——**3 条全部不含「屏状核」**，实际匹配的是关键词里的字面「M」（M胆碱受体）。**UI 搜索框提交同样复现** → 是维普布尔解析器不认 `M=` 前缀，**非 URL 编码问题** |
| ④ | **URL 参数一律不生效** | 翻页 `&page=2`/`&p=2` **都返回第 1 页**；期刊级别筛选 `&QK=bdhx` **也不生效**。二者**都只能点击 UI** |

> ⭐ **贯穿维普的一条规律**：**凡是「结果集的二次操作」（翻页、筛选），URL 参数一律无效，只能走 UI 点击。**
> 与 ③ 同源——维普把状态放在前端，不反映在 URL 上。

→ ⭐ **维普正确用法：单概念式全量取回 → 本地筛查求交。**
   工具已内置**硬拦截**：检出 `AND/OR/NOT` 即拒绝执行（需 `--force` 方可通过）。

### 🔴 知网的坑（与维普**不同**：知网布尔式可用！）

| # | 坑 | 表现 |
|---|---|---|
| ① | ⚠️ **题名单元格有两种写法 → 静默丢 1/3** | A 期刊行 `<td class="name"><a …>`；B 报纸/会议行 `<td class="name"><div><div><a …>`。**只匹配 A 时 87 条只解析出 67 条，且不报错**。故正则必须容忍 `<div>` 包裹，且不能假定 `href`/`target` 先后 |
| ② | **检索是 AJAX，URL 不变** | 输词回车后 URL 仍是 `defaultresult/index`，结果由 `POST /kns8s/brief/grid` 返回。**不能用 URL 构造检索** |
| ③ | **「在结果中检索」按钮在结果页取不到** | 结果页的 `#txt_search` **输入不进去**（value 为空），`button.behavior-searchinresult` 也取不到可见实例 |
| ④ | **未登录 → 摘要不可得** | 详情页报「您的 IP 已超出中国大陆的许可使用范围…暂无法登录」。**可读题录/关键词/DOI；读不到完整摘要** |

### ⭐⭐ 知网正确用法：**交叉检索**（这是它比维普强的地方）

```python
# ✅ 回首页 → 检索框写 'A AND B' → 回车 → 读 共找到 N 条
tab.get('https://kns.cnki.net/kns8s/defaultresult/index')
box = tab.ele('css:#txt_search'); box.clear(); box.input('屏状核 AND 精神分裂'); box.input('\n')
# 命中数：re.search(r'共找到\s*</span>\s*<em>([\d,]+)</em>', html)
```
- **`A AND B` 实测可用**（`屏状核 AND 精神分裂` → 1）；`SU=` 之类专业检索语法在简易框里**不行**
- ⚠️ **命中 0 时页面没有「共找到」** → 解析为 `None`，**须按 0 处理**，不要当成解析失败
- ⭐ **意义**：知网「主题」字段 = 题名+关键词+**摘要**，所以交叉检索能命中**本地筛查查不到的层**

> ⭐ **方法学价值（已升格为 FACT.md §五 Stage 1 的一条，该条仍常驻）**：
> **本地筛查只能看标题/作者/刊名；能用库内交叉检索就用它。**

### ⭐ 由此得出的一般纪律

> **「不报错」不等于「检索式生效」。**
> 任何检索式都必须配**对照组**（单概念命中数）来验证它确实被解析了。

> **解析条数必须与库里标称的命中数对账。** 对不上就是解析漏了，且不会报错。
> 本项目已在维普（裸词/布尔假阳性）与知网（题名两种写法）**各踩一次**。

与 §五 Stage 1「零证据复核」的分层检索纪律**同源**（该纪律仍常驻 FACT.md）。

### ⭐⭐ 质量过滤：用数据源自带分级，**勿外挂期刊名单**

**维普**：结果页左侧自带一组收录/级别筛选项，每项带计数，源码形如
`<a data-search="QK=bdhx#北大核心期刊">…<tt>14</tt></a>`。

| 代码 | 含义 | 代码 | 含义 |
|---|---|---|---|
| **`bdhx`** | **北大核心期刊** | `scopus` | Scopus |
| **`zgkjhx`** | **中国科技核心期刊** | `rccse` | 武大 RCCSE 核心期刊 |
| **`cscd`** | **中国科学引文数据库** | `pubmed` | 生物医学检索系统 |
| `jst` | 日本科技振兴机构 | `cas` | 化学文摘 |
| `ic` | 哥白尼索引 | `核心刊`/`普通刊` | 综合二分（仅在 facet JSON，无对应链接） |

**知网**：结果行的 `<td class="data">` 给出**数据库类型**（期刊 / 硕士 / 博士 / 报纸 / 中国会议 / 国际会议 / 科技成果），
可直接按此过滤——知网**收报纸与学位论文**，噪声比维普更大。

**为什么优于外挂名单**：与记录**同源**、覆盖**该库收录的全部学科**、**无许可证问题**、**不过期**。

> 🔴 **外挂方案的实测证伪（2026-09-22）**：曾推荐 gleaner 的 `cnki_journal_tiers.json`，
> 下载验证后发现：**340 种里 经管 185 + 人文 134 + 理工 10，医学 0**；
> 其 `intl_journal_tiers.json` 的 `meta` 明写 `filter: Elsevier ∩ ASJC(14/20)`
> （ASJC 14=商业管理、20=经济金融，**学科定向筛选**）。
> **拿我们那轮 31 条记录的 22 种中文期刊去比对 —— 命中 0 / 22。**
>
> → ⭐ **教训（已上升为 FACT.md §〇 的偏好，该条仍常驻）**：**推荐工具前必须验证覆盖范围，不能只读 README。**
> 「某项目里有这个文件」≠「这个文件覆盖我们要的学科」。
> **一般化**：**「数据源自带的元数据」通常优于「外挂的第三方名单」**——
> 前者与数据同源、同覆盖、同更新；后者要额外解决学科匹配、版本、许可证三个问题。
