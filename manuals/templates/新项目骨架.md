# 新项目骨架模板

> 建新项目时，复制本结构到 `<项目名>/`，并按括号提示填写。

## 项目目录

> 以下为**推荐命名**（对齐 TRS_EEG / 精神分裂症体重管理 两个在研项目的成熟习惯），按项目类型增减：

```
<项目名>/
├── _MOC_<项目名>.md        # ⭐ 项目索引：项目一句话 + 研究逻辑 + 决策记录 + 关键证据 + 更新历史
│                           #   （纯综述/调研类项目可用 README.md 替代，见体重管理先例）
├── 00_项目总览/            # 调研方案、进度.md（分工/时间线/状态）、思路整理
├── 01_文献调研/            # 调研报告、可行性评估、逐篇讲解（按思路/子主题分子目录）
├── 02_证据表/              # 证据表（xlsx+md 单一数据源）+ 核查报告 + 模板
├── 03_综述/                # 模块/思路综述、整合综述、呈送导师版、核查报告
├── 04_PPT与图表/           # PPT 稿/成品、图表设计方案、figures/ 图表
├── 05_知识整合/            # 文献矩阵、证据总览、存档（可选）
├── 06_逐篇讲解/            # 参考文献逐篇讲解（可选）
├── 07_候选课题/            # 候选课题（00_现行体系/01_参考研究/_归档，可选）
├── _scripts/               # 脚本（命名带说明）
└── _归档/                  # 旧版本/被取代文件（确认整合后可归档或删）
```

## 同时要做的 3 件事

1. **建工作日志**：`工作日志/<项目名>_工作日志.md`（复制 [[_流程与工具/工作日志模板]]）
2. **登记总览**：在 [[<系统>/科研工作总览]] 加一行（状态/最近活动/下一步/索引/工作日志链接）
3. **建索引**：创建 `_MOC_<项目名>.md`（或 README.md），第一条就写清"项目一句话"

## 目录命名约定

- 编号子目录：`00_` 开头为总览/索引，`01_`~`07_` 按工作流阶段，`_` 开头为元文件/归档
- 文件名：中文主题名，避免"最终版 v2"类命名；需区分版本时用日期后缀 `_YYYYMMDD`
- 索引：研究项目用 `_MOC_<项目名>.md`，纯综述/调研类可用 `README.md`（与 TRS_EEG / 体重管理先例一致）
- 交接文档：`<项目名>_新会话对接_YYYYMMDD.md`，旧版移入 `_归档/` 只留最新

## 工作记录触发

- 每个里程碑交付物完成 → 写一条工作日志 + 运行 `session-handoff` 生成交接快照
- 会话水位过半 → 主动交接，勿等上下文超限
