# 出稿检查总表

> **怎么用**：不从头读。**找到你当前阶段所在的行，照命令跑，对判据。**
>
> 全流程地图见《全流程总纲》§二；本文只给**每步跑什么命令、判据是什么、不过怎么办**。

---

## 一、四侧与五门（速览）

```
A 文献侧 → G0 检索层 → A2 证据表 → G1 入库
B 内容侧 → B2 自检 → G2 内容门禁 → B3.5 理解确认 → G3 理解门禁 → B4 制作稿
C 交付侧 → C1 生成 → C2 视觉验证 → G4 交付门禁 → C3 复核 → C4 快照
D 课题设计（仅立项）→ D1–D5
E 研究执行与成果产出（**立项之后 · 跨月/年**）→ E1 数据 → E2 缺失 → E3 SAP执行 → E4 结果报告 → E5 论文 → E6 投稿 → E7 归档
```

| 门 | 一句话 | 在哪一节 |
|---|---|---|
| **G0** 检索层 | 去重 / 存在性 / 元数据 / 版本，四项全过 | 下表 A 侧 |
| **G1** 入库 | PMID ↔ DOI 一一匹配 | 下表 A 侧 |
| **G2** 内容 | 排他性断言 = 0 | 下表 B 侧 |
| **G3** 理解 | 逐页一句话说得出 | 下表 B 侧 |
| **G4** 交付 | 边缘/边距/四角 全 0 | 下表 C 侧 |

> ⚠️ **唯一的回改回路**：C2 视觉验证发现问题 → **回 B4 改制作稿**（不是直接改 SVG）。
> 否则下次重新生成又会被覆盖。

## 二、逐阶段详表（**照本表跑**）

### A 侧 · 文献

| 步 | 动作 | 命令 | 判据 | 不过怎么办 |
|---|---|---|---|---|
| A1 | 抓元数据 | `pubmed_meta_fetch.py --file pmids.txt -o meta.json` | 卷期页缺失留空，**不硬填** | 标注「待出版方确认」 |
| **G0** | 去重+存在性 | `verify_pmid_doi.py --doi "10.xxx"` | 四项全过 | 剔除重复 / 查无此文 |
| G0 | 质量快筛 | `quality_screen.py --pmid-file pmids.txt -o 快筛` | **排序用，不淘汰** | 查不到的条目会显式列出 |
| A2 | 建证据表 | `build_evtab.py --data ev.json -o out/` | 10 列 PICO 填全（+2 列期刊指标可后补）| — |
| **G1** | PMID↔DOI | `verify_pmid_doi.py --pair "PMID\|DOI"` | 一一匹配 | 🔴 **手填 PMID 一律按 DOI 反查** |

### B 侧 · 内容

| 步 | 动作 | 命令 | 判据 | 不过怎么办 |
|---|---|---|---|---|
| B2 | 引用/断言/数字 | `check_language.py 讲稿.md 制作稿.md` | **排他性断言 = 0** | 补出处 |
| B2 | 身份匹配 | `check_persona.py 讲稿.md --kind 讲稿` | C1–C8 逐条**人工**判 | ⚠️ **命中≠要改**，见 §四 |
| B2 | 对照清单 | `内容自检清单.md` + `内容复盘 §三 八条标准` | 逐项过 | — |
| **G2** | 内容门禁 | 上述全过 | 排他性断言 = 0；缩写首次全展开 | **必须过**（不分档）|
| B3 | 去 AI 味 | `PPT文稿去味清单.md` | 逐页分场景 | — |
| B3.5 | 理解确认 | `理解确认清单模板.md` | 术语无空白 · 追问全答上 | 🔴 **可被自己糊弄，最贵** |
| **G3** | 理解门禁 | 逐页一句话说得出 | 说得出 | 说不出来就别做 PPT |
| B4 | 写作**规范** | `写作禁用词与句式清单.md` | 口语节拍保留 / 口语化措辞清理 | 见 §三 |
| B4 | 写作**边界** | `PPT与讲稿_身份匹配约束.md` | 三问 + 两条边界 | 见 §四 |

### C 侧 · 交付

| 步 | 动作 | 命令 | 判据 | 不过怎么办 |
|---|---|---|---|---|
| C1 | 讲稿→备注 | `make_notes.py 讲稿.md -o <项目>/notes --match-svg <项目>/svg` | 页页有备注 | — |
| **C1** | 一条命令出片 | `ppt_build.py <项目目录>` | 四阶段全过 | 失败即停，看报错 |
| C2 | 源体检 | `ppt_check.py <svg目录>` | **ERROR = 0** | 按提示改；H 项会拦导出致命错 |
| C2 | 成品体检 | `render_and_qa_pptx.py <pptx>` | 边缘/边距/四角 正常 | — |
| **G4** | 交付门禁 | 读 PNG 语义判读 | 无溢出 / 错位 / 口径错误 | — |
| **C3** | 隐藏元数据 | `check_metadata_leak.py <文件或目录>` | **对外场景下：真实名 / 机构 / 备注页 / 隐藏页 = 0** | 见下 ⚠️ |
| — | 跨文档口径 | `ppt_check.py --docs` | 全库一致 | 改计数 |

> ⚠️ **C3 隐藏元数据**——**逐页看内容查不出来的一类泄露**。
> 三个场景必跑：① **做审稿人**（稿件含可识别信息需回避）；
> ② **自己投稿盲审**（`--scene blind`）；③ **组会/外报 PPT 含未发表数据**
> （如禁运期内的试验数据）——**备注页会随文件一起外发，隐藏页也仍在文件里**。
>
> 单机自用改名不影响，**只有对外才构成泄露**。
> 🔴 **该脚本只报不改**——改元数据可能损坏文档，处置由人决定。

## 三、六条轴，**别混着查**

**混着查会互相误报**——同一个词，讲稿里是对的，幻灯片里是错的。

| # | 轴 | 在哪 | 查什么 |
|---|---|---|---|
| ① | 措辞的文体适配 | `写作禁用词与句式清单.md` | 口语节拍 vs 口语化 |
| ② | 说法准不准 | `内容复盘` §三 八条标准 | 自足 / 可答 / 有出处 / 不越原文 / 不哄 / 不设问 / 科学表述 / 维度齐 |
| ③ | 像不像他写的 | `PPT与讲稿_身份匹配约束.md` | 术语层 / 引据层 / 立场层 |
| ④ | 像不像人写的 | `PPT文稿去味清单.md` | AI 味、套话 |
| ⑤ | 引用与断言 | `check_language.py` | 自足 · 排他性 · 量词 · 缩写 · 数字口径 |
| ⑥ | 身份匹配机检 | `check_persona.py` C1–C8 | 保守 / 越级 / 引据 / 回指 / 书面语 / 缩写 / 长句 / 口语化 |

**② 与 ③ 最容易混**（都是"话该怎么说"，但轴不同）：

| | ② 不越原文 | ③ 越级表述 |
|---|---|---|
| 问 | **证据强度**：原文有这么强吗 | **立场**：待检的口气他拿得住吗 |
| 例 | 「没达标」→「相对疗效尚未确立」 | 「这证明了」→「这项研究提示」 |

> ② 管"别把人家的话说重"，③ 管"别把自己的位置站高"。

## 四、三条使用纪律

**1. 命中 ≠ 要改。**
`check_persona.py` 报「可能」不代表要删——**写证据边界时「可能」是正确用法，
写结论时要人工判断**。

**2. 讲稿与幻灯片要求不同。**
同一个词：讲稿要**口语**（口语节拍保留），幻灯片要**书面**（跳读，没有上下文兜底）。
用 `--kind` 指定，别用错。

**3. 门禁分两种。**
- **硬门禁**（必须过）：**G0 检索层** · G1 入库 · G2 内容 · G3 理解
- **软检查**（提示用）：`check_persona` 全部 · `check_language` 的 ①③④（启发式）
- `check_assets` 同样分档：第 1–3 类硬门禁，第 4 类提示
