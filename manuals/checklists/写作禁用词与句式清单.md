## 〇、**口语节拍 ≠ 口语化**

口语节拍与口语化的区分，是当初 87 处清理里**最容易搞反**的地方。审计明确保留了 4 处"形式上缺主语"的表述。

| ✅ **保留**（口语节拍） | ❌ **清理**（口语化措辞） |
|---|---|
| 「**三条原因。**」——小节起拍 | 「**卡在哪**」——口语动词 |
| 「**一共四条**，我都先说在这里。」——回指清楚 | 「**分量最重**」的一篇——程度夸张 |
| 「前三条早就成立，第四条刚刚才成立。」——紧接上文 | 「那**唯一的那一篇是什么**？」——自问自答 |

> **判据**：**它在承担节奏功能，还是在偷懒？**
> 承担节奏的短句、省略，**补全反而拖沓**。

## 一、按**文体**分流（关键）

同一个词，在讲稿里可能是对的，在幻灯片上就是错的。

| 文体 | 要什么 | 本清单怎么用 |
|---|---|---|
| **幻灯片文字** | **书面、简洁、自足** | **全表适用**——线性跳读，没有上下文兜底 |
| **讲稿 / 备注** | **口语、能一口气念完** | **只适用 §二「必删」**；口语动词与节拍**保留** |

```
幻灯片：宁可干一点，也不要"讲得热闹"——听众是跳读的
讲稿：  宁可口语一点，也不要"念论文"——你是说给人听的
```

## 二、必删（两种文体都清）

| 类型 | 例 | 为什么 |
|---|---|---|
| **降智解释** | 「**这句话的意思是**：…」「也就是说，…（重述一遍）」 | **不哄**——把它写清楚，而不是加一句翻译 |
| **自问自答** | 「那**唯一的那一篇是什么**？——是 Altar 1986。」 | **不设问**——把答案直接写出来 |
| **空泛夸张** | 「**极其**重要」「**非常**显著」「**分量最重**」 | 程度靠**证据**给，不靠副词 |
| **非科学措辞** | 「氯氮平**为什么独**」「**卡在哪**」「**绕不开**」 | 换成科学表述：「独特疗效的来源」「该环节的瓶颈」「必须纳入」 |
| **演义 / 媒体化** | 「进口**双雄**」「仿制**大军**」「价格战**混战**」「**领跑**」「**抢跑**」「**洗牌**」「权重**跳水**」 | 直述规模与主体：「**已获批 6 款，国产 4 款**」「**十余家企业已提交申请**」「**首款获批**」「**价格由 1,893 元降至 987 元**」 |

> **演义/媒体化** 一类是 2026-09-21 用户点名要求加入的（原话："不许出现任何这样戏谑化的词语，写水浒传呢？"）。
> **判据**：**待检的句子能出现在期刊论文或药监局公告里吗？不能，就重写。**
> 引申号（「」""）包裹的比喻性词汇同样算——**不要以为加引号就合规**。
> 陈述分歧或竞争时用中立动词：**申报 / 获批 / 受理 / 授权 / 共同开发**。

> 这四类**在讲稿里也删**——口语不等于不精确。

## 三、幻灯片专用（讲稿可保留）

| 类型 | 例 | 幻灯片上改成 |
|---|---|---|
| **标题替听众下结论**（2026-10-12 加） | 「两条线各自成熟，交叉处为空」·「这不是『没人想到』」·「从关联到因果」·「这个空白怎么读」 | **直白写明本页讲什么**——标题**只标内容、不表态**。例：「背景：氯氮平与屏状核」·「屏状核与症状的关联：动物证据」·「空白的三个层次」<br>⚠️ **页标题与页内落点分开**：结论放**页内落点**，不放标题 |
| **指示听众怎么读**（2026-10-12 加） | 「下表只回答一个问题：…吗？…吗？」·「先看…再看…最后看…」·「这个形状本身就是结论」· 表格列名写成问句 | **直接给内容**——表头写清**表是什么**，列名用**名词**（「人脑分布研究」「覆盖脑区」「屏状核」），不写「怎么读表格」。<br>⚠️ **听众不是不会看表**；删掉引导语，直接给数据 |
| **用指代代替点名**（2026-10-12 加） | 「那套方法」·「那篇文章」·「那个研究」·「该轴」·「这五条」 | **每处引用点名**「第一作者 ＋ 年份 ＋ 刊名」；**指代对象就地重述**（「该轴」→「血清素能轴」）。<br>⚠️ 幻灯片与口播**不是线性阅读**，听众翻不回去 |
| **落点后再补一句解释**（2026-10-12 加） | 「这两条是链③ 的全部立足点」·「它不是一块说不清的灰质」·「这正是课题的落点」·「这个形状本身就是结论」·「换三个变量就是……」 | **落点说完就停**——不追加「所以这很重要」式的总结句。<br>⚠️ **页脚不写总结句**；同一件事讲两遍属重复 |
| **贴「类型」标签**（2026-10-12 加） | 「类型：人体·关联 / 动物·因果」这类**判定标签** | **改标「研究方法」**——「结构 MRI 体积测量 ＋ 中介分析」「屏状核局部抑制 ＋ 5-choice 行为范式」。<br>⚠️ 标签只说明「这算哪一类」，**研究方法才有复用价值**；**事实性分组（人体 / 动物）可保留为分组小标题** |
| **口语动词** | 卡在、绕不开、踩坑、跑通、钉死 | 受限、必须纳入、存在问题、验证通过、确定 |
| **程度词** | 特别、相当、挺、蛮、有点 | 删，或换具体量级 |
| **第一人称口语** | 我觉得、咱们、说白了、其实 | 删（幻灯片不出现"我"的口气） |
| **指示代词起句** | 这个、那个、这边 | 补全指代对象 |
| **口头连接词** | 然后、接下来、所以呢 | 幻灯片靠**排版**表达顺序，不靠连接词 |

## 四、出稿前怎么用

**机检**（能查的先查）：
```bash
python _scripts/check_persona.py <幻灯片文字.md> --kind 幻灯片
python _scripts/check_persona.py <讲稿.md>      --kind 讲稿
python _scripts/check_language.py <文稿.md>       # 引用/断言/数字 三条另查
```

**人工过**（机检查不到的）：

- [ ] 逐页问：**待检的句子是在承担节奏，还是在偷懒？**
- [ ] 讲稿：**念一遍**，磕巴的地方是写的问题
- [ ] 幻灯片：**想象跳读**——单看待检的句子能否看懂？
- [ ] 有没有"降智解释"和"自问自答"？（这两类机检容易漏）

## 五、与其它几份清单的分工

| 清单/脚本 | 管什么轴 |
|---|---|
| **本文件** | **措辞的文体适配**（口语化 vs 书面 / 节拍 vs 偷懒）|
| `内容复盘` §三 八条标准 | **说法准不准**（自足 / 可答 / 有出处 / 不越原文 / 不哄 / 不设问 / 科学表述 / 维度齐）|
| `PPT与讲稿_身份匹配约束.md` | **像不像他写的**（术语层 / 引据层 / 立场层 + 两条边界）|
| `PPT文稿去味清单.md` | **像不像人写的**（AI 味、套话）|
| `check_language.py` | 引用自足 · 排他性断言 · 空泛量词 · 缩写 · 数字口径 |
| `check_persona.py` | 过度保守 · 越级 · 引据悬空 · 回指 · 书面语 · 缩写 · 长句 · **口语化** |

> 四份文档 + 两个脚本，**六个轴互不重叠**。用之前先想清楚这次要查哪个轴——
> **混着查会互相误报**（例：讲稿里的"那篇综述"是对的，幻灯片里是错的）。
