## 〇、先读：本清单管什么、不管什么

**两张清单的分工**：

| | `PPT文稿去味清单.md` | **本清单** |
|---|---|---|
| 管什么 | 文字**像不像人话**——AI 味、套话、套式句式 | 内容**能不能被接住**、断言**站不站得住** |
| 典型问题 | 「具有重要意义」「研究表明」（无出处） | 「PV 阳性」是什么？「密度」是什么的密度？ |
| 何时用 | ①.5 / ②.5 **去味关卡** | **①.2 内容自检**（内容稿定稿后、去味之前） |

> ⚠️ **两道关不能互相替代**。文字干净但读者接不住，和读者能接住但文字有 AI 味，是两种失败。

## 一、三条判据：什么该解释、什么该删 ★

「为专家准备就删掉常识」与「别默认我知道」**不矛盾**，但判据要精确。

### 判据 A · 看**领域归属**，不看难度

> **判据在于"同一个专家在不在这行"。**

一场跨领域的汇报里，**听众每换一个领域，"常识"的范围就变一次**。

| 删 | 必须解释 |
|---|---|
| 属于**听众本行**的常识 | 属于**汇报核心领域、但听众不在这行**的术语 |
| 例：「TRS 约占精分的 15–30%」——精神科医生都知道 | 例：「PV / SST 阳性中间神经元」——属屏状核环路领域的词 |

**操作**：先列出这场汇报跨了哪几个领域，标注**哪个是听众的主场**。
**非主场的术语一律要铺垫。**

### 判据 B · 我自己查了资料才懂的，听众也需要 ★★

> 本项目的原话：「我初看时云里雾里，**自己查找了很多资料才搞明白**这些缩写都是什么」

**这句原话就是判据本身。** 准备过程中查过资料的每一个概念，都记下来——**这份记录就是需要解释的清单**。

### 判据 C · 术语密度 > 3 且无解释 → 读者放弃

一句话里连续出现 **3 个以上**未解释的陌生术语，读者会切到"记个印象"模式，不再尝试理解。

**操作**：逐页数一下"一句话里的未解释术语数"，超 3 就拆句或加注。

## 二、八条把关标准

**以下八条是从实际纠正中归纳的，几乎每一次返工都能归到其中一条。**

| # | 标准 | 一句话判据 | 反例 → 正例 |
|---|---|---|---|
| **1** | **自足** | 待检的这一处**单独**拿出来，读者知道说的是什么吗？ | 「那篇综述」→「Murray 等 2026 年 *Biological Psychiatry* 综述」 |
| **2** | **可答** | 填进来的数字/名词，我能回答"**这是什么的口径**"吗？ | 「密度」→「**α2 肾上腺素能**密度」 |
| **3** | **有出处** | 待检的这句**排他性断言**（唯一/首次/主流/无效），出处在哪？ | 「当前主流」→「Murray 等 2026 年综述所给出的结论」 |
| **4** | **不越原文** | 原文说得有这么强吗？ | 「没达标」→「**相对疗效尚未确立**」 |
| **5** | **不哄** | 待检的句子是在**解释**，还是在**降智**？ | 「**这句话的意思是**：…」→ 删，把含义并进原句 |
| **6** | **不设问** | 我会在组会上**当众自问自答**吗？ | 「那唯一的那一篇是什么？」→ 删 |
| **7** | **科学表述** | 这个说法是科学措辞，还是口语？ | 「氯氮平**为什么独**」→「氯氮平**独特疗效的来源**」 |
| **8** | **维度齐** | 同一列 / 同一组的各项，答的是**同一个问题**吗？ | 「人体·精分 / 动物·因果」→ 强度前置，统一为「相关性（人体）/ 因果（动物）」 |

> **第 5 条与"要不要解释"的区别**：
> | 降智 | 解释 |
> |---|---|
> | 「**这句话的意思是**：屏状核偏离越大……」——**重复已说过的话**，还加引子 | 「PV 打在胞体上，**决定神经元什么时候能放电**」——**补上缺失的部分** |
> | 判据：**有没有新信息？** | |

## 三、概念铺陈：四种缺口

### 缺口 1 · 名词未落地

- **缩写未展开**：`PV` `VBM` `ALE` `DTI` `ENIGMA` `PSD` `D2`…
- **属性未交代**（最容易漏）：这些细胞是 **GABA 能还是谷氨酸能**？是兴奋性还是抑制性？
- **判据**：一个不在本领域的人，**能不能从字面猜出它是什么？**

### 缺口 2 · 关系未说明

- 「VIP 阳性**去抑制**」——去谁的抑制？
- 「对输出做**非线性过滤**」——怎么个非线性法？
- **判据**：**动词的宾语在不在？机制说不说得通？**

### 缺口 3 · 术语密度过高（见判据 C）

### 缺口 4 · 落点未衔接

- 这一页讲的东西，**跟本课题什么关系**？
- 每一页都该有一句「**这一页要回答什么问题**」

### 解释放在哪一层（分层承载）

**页面空间有限，解释不必都挤在页面上。**

| 层 | 承载什么 | 例 |
|---|---|---|
| **页面正文** | 论点 + 关键数字 | 「GABA 能中间神经元仅占 7–12%，却决定全部输出」 |
| **表注 / 脚注**（16px 灰） | **缩写展开、属性、定义** | 「四者均为 **GABA 能**中间神经元；PV = parvalbumin（小清蛋白）…」 |
| **讲稿口播** | 机制、"所以呢"、为什么不是别的 | 三类细胞各管一段的展开 |
| **备用页 / 概念速查** | 追问时的弹药 | 补课笔记 |

> **表注是最被低估的一层**——16px 灰字一行能解决整页的缩写问题，**不占正文行**。

## 四、表格自检

**列名是写表格时定的，单元格是填的时候想的——两者不在同一时刻决定，所以必然脱节。**

**操作方法：填完表，倒着读一遍，逐格问——**

- [ ] **这一格答的是列名问的问题吗？**（「物种」列填「综述」→ ❌）
- [ ] **同一列的各项，回答的是同一个问题吗？**（「人体·精分」vs「动物·因果」→ 第二项一个讲人群、一个讲强度 → ❌）
- [ ] **同一格的多个值，是不是在答不同的问题？**（「有｜解释了…无｜喹硫平…」→ 一格内两个"有/无" → 读作自相矛盾）
- [ ] **列名本身是否准确？**（「证据类型」实际填的是"物种+人群" → 改名「证据强度」）
- [ ] **单元格里的动词，宾语在不在？**（「不支持」→ 不支持什么？）

## 五、引用自检

- [ ] **每处引用是否自足**？——独立可读，**禁用回指**：「那篇综述」「该研究」「前述文献」「该文」
- [ ] **格式统一**：第一作者 + 年份 + 刊名
- [ ] **英文期刊写原名**，不译中文（*Biological Psychiatry*，不写「生物精神病学」）
- [ ] **转述是否降级**？二手陈述要写「有研究报告」「综述称」，**并追到原始文献再定**
- [ ] **引文链是否独立**？——同一批来源被反复转引，**不构成新证据**
- [ ] **数字与文献是否对得上**？——每个数字回到**原文对应语句**核对

> ⚠️ **前三条的口径出处是 `术语表.md` §四 著录与引用类**——
> 格式规则如需修改，**改《术语表》**；本节只保留可勾选的操作形式。

> ⚠️ **本项目最贵的一类问题**（14 处）全部出自此处：
> Rioux 1999 被当成密度研究、Wong 2021 的转引被当成 M4 证据、
> 0.21% 的反推值被当成文献值、Xiao 2013 的元分析被当成原始研究。
> **共同点：把二手陈述当成一手证据在用。**

## 六、数字自检

- [ ] **填进来的数字的口径是什么**？（准确率？占比？倍数？相对于什么？）
- [ ] **比较的基准是什么**？（较对照 / 较基线 / 纵向变化——**同一句里不能混**）
- [ ] **有没有参照物**？（13% 算大算小？g = 0.63 什么量级？）
- [ ] **同一数字全篇是否只出现一处**？（本项目曾出现 0.21% 与 0.25–0.27% **在同一份讲稿里共存并互相矛盾**）
- [ ] **算出值有没有被当成文献值**？（反推、换算得来的数值必须标注"推算"）

## 七、排他性断言自检（硬规则）

**正向断言错了只是不够好；排他性断言错了是"武断"。**

以下词一旦出现，**必须能指到具体出处**：

```
唯一  首次  首个  第一个  独创  当前主流  无效  不独特
没有区分力  没人研究过  零篇  从未有人  无一例  没有任何一项
```

**若出处是"我们自己的检索"**，则必须写明**分层与库名**：

> ✅ 「在 **PubMed / Europe PMC / OpenAlex** 三库交叉检索下，标题级 **0 篇**、
> 标题/摘要级 **3 条中 2 条为会议材料**（已排除），**有效 1 篇**」
>
> ❌ 「**零篇文献**」「**没人做过**」

## 八、自动检查脚本

```bash
cd "<vault>/<手册>_scripts"
python check_language.py <你的稿子.md>
```

**五类检查**：

| # | 检查 | 性质 |
|---|---|---|
| ① | 回指词（跨段未点名） | 启发式，人工复核 |
| ② | **排他性断言·未见出处** | **硬规则** |
| ③ | 空泛量词（很多/一些/大量） | 启发式 |
| ④ | 缩写首次出现·未见展开 | 启发式 |
| ⑤ | 数字-口径（列出供人工核） | 汇总 |

**常用参数**：

```bash
python check_language.py 讲稿.md 参考稿.md 制作稿.md     # 多文档
python check_language.py 讲稿.md --terms 术语白名单.txt   # 跳过已知术语
python check_language.py 讲稿.md --only 2                 # 只跑硬规则
python check_language.py 讲稿.md --quiet                  # 只看汇总
```

**术语白名单文件格式**（每行一个，`#` 注释）：
```
DOI
PMID
TRS=治疗抵抗性精神分裂症
KOR=κ-阿片受体
```

> **脚本只做"可自动化的部分"**——语义判断（列义、口径、概念铺陈）**必须人工过**。

## 九、六条界限（与去味清单共用）

1. 数字被"概括化"
2. 事实关系被改
3. 条件、范围、否定、时态在改写中丢失
4. `[n]` 文献角标丢失或错位
5. 单位丢失
6. 不同队列的数字被并列比较

## 十、使用时机

```
① 内容稿定稿 → ①.2 内容自检 → ①.5 去味关卡 → ② PPT制作稿 → ②.5 制作稿去味 → ③ 生成PPTX → …
                    ↑ 本清单                      ↑ 去味清单
```

**为什么在去味之前**：**内容问题比文字问题更贵**。
文字有 AI 味，改词就行；内容接不住，要重写整页——
而如果先去了味再改内容，**去味的工夫全白费**。
