## 四·五、深读结果（**医学口视角，2026-09-19 补**）

按要求**只读不装**，读了两份最相关的实际内容。

### ⭐ 最强发现：`grant-thinking-cn-biology`（365-skills，**MIT**）

**它的定位是「诊断型」，不是「写作型」——而这恰好完全契合 NSFC 的 AI 硬约束。**

技能开篇即写明：

> You are **not** mainly a writing assistant.
> **Do not default to section writing** unless explicitly asked.
> Default to **diagnosis, restructuring, fundability analysis, and reviewer-aware reasoning**.

对照 NSFC 官方的规定"**不得使用生成式 AI 直接生成申请书**"——
**这个"只诊断、不代写"的设计，正是合规的形态。**

#### 它的十层推理

```
1  资助层级匹配    问题是否配得上青年/面上/重点
2  问题合法性      真问题，还是时髦方法/资源
3  机制主线        现象→不确定性→机制→假设→可检验目标
4  架构层次分离    ← 见下，最有价值的一层
5  生物学深度 vs 描述性过剩
6  创新纪律        创新必须「具体、有界、可见、可辩护」
7  可行性          不是平台数量，是"能不能回答提出的问题"
8  评审视角扫描    同时给「最强支撑点」与「最可能被拒点」
9  边界意识        该砍什么、什么降为次要
10 战略收束        为什么是这个问题、为什么现在、为什么这个层级
```

#### 🔴 第 4 层「架构层次分离」——**最值得采用的一条**

它要求**永远分开这八层**，不许它们互相混淆：

```
背景 → 空白 → 科学问题 → 假设/模型 → 目标 → 研究内容 → 技术路线 → 预期产出
```

并点明：**多数弱标书败在这几处混淆**——

| 混淆 | 说明 |
|---|---|
| 意义 ↔ 问题 | 把"重要"当成"要解决什么" |
| 问题 ↔ 目标 | |
| 目标 ↔ 实验 | |
| **内容 ↔ 方法** | |
| **方法 ↔ 创新** | |

#### 三条判据

> - **差异表达 ≠ 机制**
> - **多组学 ≠ 深度**
> - **技术复杂 ≠ 科学成熟**
> - 广谱 profiling ≠ 解释力

以及：

> **Innovation should be: specific, bounded, visible, and defensible.**
> A stronger proposal is usually **more selective, not more crowded**.

#### 自带 12 项自检（`checks.md`）

含"是否区分了**主题重要性**与**立项合法性**""是否避免了奖励含糊的新颖性语言"
"是否**同时**给出最强逻辑与最大否决风险"。

### ⚠️ 关键限制：它是**生物学（生命科学部 C）**，不是**医学（医学科学部 H）**

| | 生命科学部 C | **医学科学部 H（你的口）** |
|---|---|---|
| 落点 | 机制、模式生物、通路 | **临床问题、患者队列、诊疗决策** |
| 样本 | 细胞/动物模型为主 | **人样本、临床队列、伦理** |
| 好的标准 | 机制清晰 | 机制清晰 **+ 临床可转化 + 伦理与可行性** |

**但**——它的**十层推理、架构分离、创新纪律、评审扫描**全是**领域无关的方法论**，
`examples.md` 里的三个例子（工具驱动型 / 只有现象没有机制 / 目标过多）
**在医学里一模一样存在**。

> ✅ **判断：方法论可直接迁移；示例与语域需换成医学场景；医学口要补"临床转化与伦理可行性"一层。**
