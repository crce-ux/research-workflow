# 国自然标书 · 医学口补充

> **为什么需要这份**：`国自然标书_诊断与架构手册.md` 改编自 **`grant-thinking-cn-biology`**，
> 那个技能的定位是**生命科学部（C）**；而你是**医学科学部（H）**。
> 两者的评审预期**不完全一样**。
>
> ⚠️ **本文件的医学口判据为待核状态**——须以当年《项目指南》医学科学部章节核对后修正。

---

## 一、两学部差在哪

| | **生命科学部 C** | **医学科学部 H** |
|---|---|---|
| **落点** | 机制、通路、模式生物 | **临床问题、患者队列、诊疗决策** |
| **样本** | 细胞 / 动物模型为主 | **人样本、临床队列、伦理** |
| **好项目的标准** | 机制清晰 | 机制清晰 **＋ 临床可转化 ＋ 伦理与可行性** |
| **常见追问** | "机制链条闭合吗" | "**这对病人意味着什么**" |
| **数据来源** | 实验产生 | 实验 **＋ 临床数据 ＋ 随访** |
| **约束** | 生物安全 | **＋ 医学伦理、知情同意、样本来源合规** |

> 🔴 **一句话**：**C 口问"机制清不清楚"，H 口还要问"这对临床意味着什么、你做不做得成"。**

## 二、医学口需补的三层

### 第 11 层 · 临床落点

**在诊断手册第 2 层"问题合法性"之上，追加追问**：

- 这个医学问题的**临床对应是什么**？——诊断？治疗？预后？机制解释？
- 若研究成功，**改变了什么决策**？（选药 / 分层 / 时机 / 监测）
- 是**临床问题驱动**，还是**从一个机制出发去找临床意义**？

| ❌ 弱 | ✅ 强 |
|---|---|
| "氯氮平疗效存在个体差异，机制不明" | "**哪些患者该优先启用氯氮平**——这决定一次换药决策" |
| "XX 指标在患者中升高" | "XX 能否**在治疗前区分应答者**，从而避免无效换药" |

> ⭐ **判据**：能否说出"**研究做成了，临床哪一步会变**"。说不出来 → 临床落点缺失。

### 第 12 层 · 患者样本与队列可行性

**医学口最容易被问倒的一层**：

- **样本从哪来**？现有队列？新招募？生物样本库？
- **能拿到多少例**？——**写具体数字**，与样本量需求**做对比**
- **随访期够吗**？（临床结局往往需要长时间随访）
- **纳入排除标准**会不会把目标人群筛空？
- 有无**竞争者已在做**同一队列/同一指标？

> 🔴 **对接 `课题设计流程手册.md` D4**：**可招募数 ≥ 样本量需求**，做数字对比，
> 不能只写"预计可满足"。

### 第 13 层 · 伦理与合规

**C 口通常不涉及，H 口必查**：

- [ ] **伦理批件**：有？申请中？批件号？
- [ ] **知情同意**形式（书面 / 口头 + 见证）
- [ ] **弱势群体**保护（精神科研究尤其要写清）
- [ ] **数据管理**：存储、权限、脱敏、保存年限
- [ ] **人遗资源**相关手续（若涉及）
- [ ] **预注册**（若为干预性研究，早于入组）

> ⚠️ **精神科研究的特殊性**：受试者可能属弱势群体，
> **知情同意的能力评估**要主动写清，不等评审来问。
>
> 详见 `课题设计流程手册.md` **D5 伦理与数据管理**。

## 三、医学口的两条特有红线

### 🔴 红线一：**不要把"相关性"说成"因果"**

临床研究多为观察性，**"X 与 Y 相关"≠"X 导致 Y"**。
`术语表.md` 与本库 `核查方法/01` 的语境四级判定在此尤其要紧。

> 措辞纪律：**"关联""提示""支持…的可能"** 与 **"导致""决定""证明"** 之间，
> 隔着研究设计的差异。

### 🔴 红线二：**不要把"机制清晰"当成"临床有用"**

C 口的机制项目可以止于机制；**H 口通常还要交代一句临床落点**。
反过来也成立：**只讲临床意义而无机制抓手，会被问"科学问题是什么"**。

> **两头都要有，且要连起来。**

## 五、与诊断手册的配合

```
《诊断与架构手册》跑 1–10 层（立项逻辑）
        ↓
本文件补 11–13 层（临床落点 / 队列可行 / 伦理合规）
        ↓
两条红线自查（相关性≠因果 / 机制≠临床有用）
```

> ⚠️ **顺序不可颠倒**：**先确认是个真问题（1–10），再补临床维度（11–13）**。
> 反过来会变成"先想临床意义，再倒推机制"——那正是诊断手册第 4 层要防的塌陷。
