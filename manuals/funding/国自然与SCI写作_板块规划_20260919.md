## 〇、⭐ 一条决定全局的设计原则

**「1–2 年后才用」意味着：现在建的东西，到时候有一半是废纸。**

NSFC **每年改版**——2026 年正文刚从三部分改成四部分。若现在把篇幅、代码、格式写死进手册，
**两年后它们不仅无用，还有害**（有人照着过期的规矩写）。

所以本板块**按"会变 / 不变"切开**：

| | **不变的部分** → **现在建** | **会变的部分** → **留占位，到时再取** |
|---|---|---|
| 内容 | 诊断框架 · 架构层次 · 创新纪律 · 评审视角 · 深度判据 · AI 合规原则 | 当年《项目指南》· 申请代码 · 篇幅限制 · 正文结构 · 撰写提纲 · 年龄/资格要求 |
| 性质 | **方法论**，与年份无关 | **规则**，逐年作废 |
| 处置 | ✅ 建 | ⏸️ **只建"去哪取、怎么核对"的指引** |

> 🔴 **规则：本板块不写死任何年度性数字。**
> 凡涉及"今年多少页""今年什么结构"的，一律写成**取用指引 + 核对清单**，
> **不写具体值**。

## 一、青年 C 的推论：**排除什么**

2026 年起青年科学基金项目更名 **C 类**，其中一条直接改变板块范围：

> **2026 年实行经费包干制，无需编制预算。**

**推论**：

| 排除 | 理由 |
|---|---|
| ❌ **预算说明书**（`nsfc-budget` 那一类） | 青年 C 包干制，不需要 |
| ❌ **参与者/团队组建** | 青年项目相关条款只涉及"申请人"，不含主要参与者 |
| ⏸️ 申请代码选择 | 属"会变"部分，到时取当年指南 |

**保留且重点**：立项依据 · 研究内容 · 研究基础 · 技术路线 · 创新点表述 · 评审视角自审。

> ⚠️ **待核实**：以上依据 2026 年政策。**1–2 年后的政策可能再变**——
> 到时**先核对当年指南**，再决定这些排除项是否仍成立。

## 三、国自然板块规划

### 3.1 现在建（三份文档）

#### ① `国自然标书_诊断与架构手册.md` ⭐ 核心

合并两样**领域无关**的方法论：

**A. 十层诊断**（源自 `grant-thinking-cn-biology`，改写为医学场景）

```
1 资助层级匹配   这问题配得上青年 C 吗
2 问题合法性     真问题，还是时髦方法/数据
3 机制主线       现象→不确定性→机制→假设→可检验目标
4 架构层次分离   ← 核心，见 B
5 深度 vs 描述   差异表达≠机制 · 多组学≠深度 · 技术复杂≠科学成熟
6 创新纪律       具体 · 有界 · 可见 · 可辩护
7 可行性         不是平台齐全，是"能不能回答那个问题"
8 评审视角扫描   同时给「最强支撑点」+「最可能被拒点」
9 边界意识       该砍什么、什么降为次要
10 战略收束      为什么是这个问题、为什么现在、为什么这个层级
```

**B. 架构八层分离**（**最值钱的一条**）

```
背景 → 空白 → 科学问题 → 假设/模型 → 目标 → 研究内容 → 技术路线 → 预期产出
```

**五处必须防的塌陷**：

| 塌陷 | 表现 |
|---|---|
| 意义 ↔ 问题 | 把"重要"当成"要解决什么" |
| 问题 ↔ 目标 | |
| 目标 ↔ 实验 | |
| **内容 ↔ 方法** | 研究内容写成技术清单 |
| **方法 ↔ 创新** | 用了新技术 = 创新 |

#### ② `国自然标书_医学口补充.md`

`grant-thinking-cn-biology` 是**生命科学部 C**，你是**医学科学部 H**。差异：

| | 生命科学部 C | **医学科学部 H** |
|---|---|---|
| 落点 | 机制、模式生物、通路 | **临床问题、患者队列、诊疗决策** |
| 样本 | 细胞/动物为主 | **人样本、临床队列、伦理** |
| 好的标准 | 机制清晰 | 机制清晰 **+ 临床可转化 + 伦理与可行性** |

→ **需补一层"临床转化与伦理可行性"**，并核对医学科学部自己的资助领域与注意事项。

#### ③ `国自然_规则取用指引.md`（**占位型，不写具体值**）

**只写"去哪取、怎么核对"**：

```
① 当年《国家自然科学基金项目指南》   ← 唯一权威
② 当年申请书撰写提纲 / 填报说明
③ 医学科学部「资助领域和注意事项」
④ 依托单位的内部要求与截止时间
⑤ 当年的 AI 使用政策（可能变化）
```

**核对清单**（每次申报前跑一遍）：

- [ ] 正文结构是几部分？篇幅上限多少？
- [ ] 青年 C 当年的年龄/资格要求
- [ ] 是否仍为包干制（决定要不要预算）
- [ ] AI 使用政策有无更新
- [ ] 医学科学部当年有无特殊要求

> 🔴 **本文件不写任何具体数字。** 数字写死了就会过期，过期的规则比没有规则更危险。

#### ④ `AI使用情况声明模板.md`（**NSFC 明文要求**）

官方规定：用 AI 跟踪研究动态、收集整理参考文献的，**必须人工核实**并**全面如实声明使用情况**、标识相关内容。

→ 模板须含：用了什么 · 用在哪一步 · 人工如何核实 · 由谁负责。

### 4.2 现在建（一份文档 + 一个工具）

#### ① `SCI投稿_选刊流程.md`

**硬过滤 + 软判断两段**（沿用 `quality_screen.py` 的四条铁律精神）：

```
硬过滤（客观轴）        软判断（人工）
├ 学科范围匹配          ├ 期刊 scope 与本文是否真合
├ IF / 分区门槛         ├ 审稿周期（社区评价）
├ 文章类型接受度        ├ 版面费 / OA 政策
└ 是否有同类发表        └ 目标读者是否对
```

> ⚠️ **判据沿用既有铁律**：**相关度是门槛，影响因子只是排序。**
> 不能因为 IF 高就选一个 scope 不匹配的刊。

#### ② `journal_match.py`（**可直接建，因为地基已有**）

你已有 `fetch_journal_metrics.py` + `_journal_data/`（中科院 2025 + JCR 2024）。
选刊工具**只需在此之上加一层**：

```
输入：稿件关键词/摘要 + 分区门槛 + 偏好
  ↓
从 _journal_data/ 做硬过滤 → 候选池
  ↓
输出：候选刊表（刊名 / IF / 分区 / 匹配度待人工判）
```

> 📌 **这正是 `paper-select-journal` 的做法**（它用内置 `2023IF.xlsx` 做硬过滤）——
> **但你不需要装它，因为你有自己的期刊数据。**
> 且它的数据是 2023 的，**比你的旧**。

### 4.3 不建

- ❌ 论文写作新流程——`paper-spine` 已在
- ❌ 期刊数据重购——`_journal_data/` 已在
