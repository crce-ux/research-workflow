# SCI 投稿 · 选刊流程

> 建立 2026-09-19。**补的是本库唯一缺的投稿环节**——写作、润色、审稿回复、引用核查都已有
> （`paper-spine` / `nature-polishing` / `nature-response` / `核查方法/01`）。
>
> **来源**：判据沿用本库 `quality_screen.py` 的 G0 四条规则；
> 硬过滤段由 `journal_match.py` 实现（**基于本库自有权威表，不依赖任何外部技能**）。

---

## 〇、这份管什么

| | |
|---|---|
| **管** | 从期刊全集里筛出**客观够格**的候选池，再叠加人工的 scope 判断 |
| **不管** | **不回答"哪本最容易中"**——它取决于稿件与 scope 的匹配，属人工判断 |

> 🔴 **硬过滤负责"够格"，软判断负责"该投"。**

---

## 一、两段式

```
① 硬过滤（客观轴）            ② 软判断（人工）
   journal_match.py             逐本问
   ├ 学科匹配（大类/小类）       ├ scope 与本文是否真合
   ├ IF / 分区门槛               ├ 近年有无同类文章
   ├ 排除预警名单                ├ 审稿周期（社区评价）
   └ 排序（IF / 分区）           ├ 版面费 / OA 政策
                                 └ 目标读者是否对
```

> ⚠️ **顺序不可颠倒。** 先筛客观够格的，再判主观合适的——
> 反过来会变成"先挑一本想投的，再找理由"。

## 二、硬过滤：`journal_match.py`

```bash
# 1) 按学科与门槛筛候选池
python journal_match.py --major 医学 --sub 精神病学 --min-if 3 --max-zone 2

# 2) 只看统计（先看池子有多大，再决定要不要收紧）
python journal_match.py --major 医学 --sub 精神病学 --min-if 3 --stats

# 3) 已有候选刊名 → 查指标
python journal_match.py --candidates my_journals.txt

# 4) 落盘
python journal_match.py --major 医学 --sub 精神病学 --min-if 5 --out 候选池.md
```

**数据源**（本地离线，权威表 CSV）：

| 文件 | 内容 |
|---|---|
| `FQBJCR2025-UTF8.csv` | 中科院分区表 **2025 升级版** |
| `JCR2024-UTF8.csv` | JCR 2024：IF / Quartile / Rank |
| `GJQKYJMD2025.csv` | **国际期刊预警名单 2025**（默认硬排除）|

> 📌 **口径必须连版本一起写**：中科院分区有**基础版/升级版**差异且逐年变动。
> 引用时写 `中科院医学2区(2025)`，**不写"中科院2区"**。

## 三、软判断：人工四问

硬过滤之后，**逐本问**：

### ① 近年有没有同类文章？

- 该刊近 2–3 年发过**同主题、同设计**的论文吗？
- 发过 → 说明**收**，但要问"我这篇比它新在哪"
- **完全没发过** → 两种可能：**scope 不收**，或**是个空白**——**必须查清是哪一种**

### ② 目标读者对不对？

| 你的稿件 | 该投 |
|---|---|
| 机制 + 生物标志物 | *Molecular Psychiatry* / *Biological Psychiatry* 一类 |
| 临床疗效 / 干预 | *Lancet Psychiatry* / *JAMA Psychiatry* / *Schizophrenia Bulletin* |
| 临床服务 / 流行病学 | *Psychiatry Research* / *Schizophrenia Research* 一类 |

> ⚠️ **投高分区刊但读者不对 = 大概率 desk reject。**
> 编辑第一问是"**这本刊的读者关心这个吗**"，不是"这个研究好不好"。

### ③ 审稿周期与费用

- 社区评价里的**平均审稿时长**（毕业/结题有时间压力时必须看）
- **OA 政策与版面费**——基金是否覆盖
- **是否只收 OA**

### ④ 有无预警

- 已由 `journal_match.py` 默认排除
- ⚠️ **但名单只到 2025**——投稿前**再核一次最新名单**

---

## 四、三条规则

**1. 相关度是门槛，影响因子只是排序。**
不能因为 IF 高就选一本 scope 不匹配的刊——**desk reject 的概率远大于收益**。

**2. 分区口径必须连版本写。**
`中科院医学2区(2025)` ✅ ｜ `中科院2区` ❌（不知道哪年、哪版）

**3. 硬过滤只给"够格"。**
`journal_match.py` 只做客观门槛；**scope 判断不可外包给脚本**。

## 五、与既有体系的对接

| 环节 | 用哪件 |
|---|---|
| 期刊指标查询（已知刊名）| `fetch_journal_metrics.py` |
| **选刊候选池（反向）** | **`journal_match.py`** |
| 论文写作 | `paper-spine` |
| 英文润色 | `nature-polishing` |
| 投稿前自审 | `academic-paper-reviewer`（5 人模拟）|
| 引用号核验 | `核查方法/01` |
| 审稿回复 | `nature-response` |
| 数字与断言核查 | `核查方法/02` |
| 盲审自查（元数据泄露）| `check_metadata_leak.py --scene blind` |

> ⚠️ **投稿前必跑**：`check_metadata_leak.py --scene blind`
> ——检查稿件里的 `creator` / `lastModifiedBy` 等**文档属性是否泄露身份**。
> 盲审场景下这是硬门槛。

## 六、选刊清单（逐本过）

- [ ] 小类匹配本文主题吗？
- [ ] 近 2–3 年发过同类文章吗？
- [ ] 目标读者对不对？
- [ ] 审稿周期可接受吗？
- [ ] 版面费 / OA 政策可接受吗？
- [ ] 已核**最新**预警名单（不止 2025）吗？
- [ ] 分区口径写全了吗（年份 + 版本）？
