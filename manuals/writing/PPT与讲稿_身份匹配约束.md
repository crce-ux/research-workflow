# PPT 文字与讲稿 · 身份匹配约束

> **一句话**：**凡是我替你写的东西——幻灯片上的字、嘴上说的话、答辩的话术——都必须读起来是「你写的」。**
>
> 判断标准是**听众会不会觉得这不是他说的**。

## 一、动笔前先定身份

**在这个场景里，你是什么身份？** 然后逐句过三问：

| 层 | 问什么 | 失配的表现 |
|---|---|---|
| **术语层** | 这个词，这个身份的人会**脱口而出**吗？ | 用了刚查来、自己还没消化的术语；或反过来，对着专家解释他的常识 |
| **引据层** | 这个出处，这个身份的人**指得出来**吗？ | 说了"有研究支持"却点不出是哪篇；或引了自己没读过的二手转述 |
| **立场层** | 这个口气，这个身份的人**拿得住**吗？ | 越级承诺、替导师下结论、把假说说成发现 |

## 二、本项目的场景锚点

### 场景 A｜组会汇报（**主要场景**）

| 项 | 内容 |
|---|---|
| **身份** | 向导师和同门汇报研究现状与一个设想的**研究生** |
| **听众** | 导师是 TRS 领域专家；同门熟悉临床与药理 |
| **术语层** | ✅ 领域术语可放开（氯氮平、TRS、MMN 直接用）<br>❌ 但**机制细节必须追到原始文献**——转述别人的综述时要点出原始研究 |
| **引据层** | 每处引用写「**第一作者 + 年份 + 刊名**」；**禁用**「那篇综述」「该研究」这类**回指**——幻灯片不是线性阅读，每处引用必须**自足**<br>（格式口径见 `术语表.md` §四，本表不复述） |
| **立场层** | 是"汇报一个调研结果 + 附带一个设想"，**不是**"我提出了一个理论" |
| **🔴 界限** | ① **不主动列导师组自己的成果**——他比谁都清楚，列出来既冗余又有"教老师"之嫌<br>② **导师的常识不必讲**（受体占有率、血药浓度、CYP1A2…这些删掉）|

> ⚠️ **第 ② 条是受众轴，不是身份轴**——"为专家准备的汇报要删掉他的常识"是**读者水平**问题。
> 别和身份匹配混为一谈：删常识是为了不浪费他的时间；不改口吻是为了不让他觉得这不是你写的。

### 场景 B｜期刊审稿

**身份**：首次审稿的研究生。界限：不引方案文件章节号、不点报告规范名、不用方法学术语下判断。

### 场景 C｜回导师 / 同门

**身份**：学生 / 同门。简洁直给，**不越级承诺**（"我会完成"可以，"我保证课题组能拿到"不行）。

## 三、两条最容易踩反的边界

### 边界 1｜**只约束表达层，不约束发现层**

真问题该指出的仍要指出，只是换个口吻——
只指出呈报缺口，不质疑对方能力。

> 判据：把句子里的措辞换掉之后，**信息量不变**，才算合格的调整。
> 如果换完措辞问题就消失了，说明你是在**回避发现**，不是调整表达。

### 边界 2｜**过度保守同样破坏身份**

通篇"可能 / 似乎 / 或许 / 大概 / 应该是"把话说虚，**既不像一个有判断力的研究者，也白丢信息量**。

> **约束的是说法本身。**
> 目标是"**像他说的**"。

**实操**：该下判断的地方下判断，但**把证据边界同时给出**——

| ❌ 过度保守 | ❌ 越级 | ✅ 像一个有判断力的研究生 |
|---|---|---|
| 这个结果似乎可能有某种潜在的关联 | 这证明了屏状核是氯氮平的作用靶点 | 这项研究提示二者有关联；但它是横断面的，**不能推因果** |

**第三种是对的身份**：敢下判断 + 说清边界。

## 四、PPT 文字与讲稿的**分轴**要求

两者身份相同，但**载体不同 → 约束不同**：

| | 幻灯片文字 | 讲稿 / 备注 |
|---|---|---|
| **受众** | 看的人（导师 + 同门） | 只有你自己 |
| **阅读方式** | **跳读、非线性** | 线性、连续 |
| **引用要求** | **每处自足**（第一作者+年份+刊名），禁用回指 | 可以"接下来""前面那篇" |
| **句子长度** | 短，可断行 | 可长，但**要能一口气念完** |
| **口语度** | 书面，但不要"论文腔" | **纯口语**，写出来是给人念的 |
| **常见失配** | 术语堆砌、句子太长、回指 | 书面语（"综上所述""值得注意的是"）、念着磕巴 |

> ⭐ **讲稿的独特判据**：**能不能一口气念完**。
> 念到一半要换气、要回看主语的句子——**是写的问题，不是念的问题**。

## 五、可机检的部分（`_scripts/check_persona.py`）

有些维度机器能查，有些只有人能动脑。**不要指望脚本代替判断**。

| 维度 | 机器能查 | 只能人判断 |
|---|---|---|
| 术语层 | 缩写是否首次展开；术语密度 | 这个词**你会不会脱口而出** |
| 引据层 | 讲稿里提到的文献能否在参考文献表定位 | 你是否**真读过**原文 |
| 立场层 | 越级表述词表；承诺类句式 | 这个结论**你拿不拿得住** |
| 边界 2 | **保守词密度**（可能/似乎/或许…） | 该下判断的地方是否下了 |

```bash
python _scripts/check_persona.py <讲稿或制作稿.md>            # 全部检查
python _scripts/check_persona.py <文件> --scene 组会汇报      # 指定场景阈值
```

> ⚠️ **脚本只报"可疑"，不下判决**。命中不等于要改——
> 「可能」在写**证据边界**时是正确用法，在写**结论**时要人工判断。

## 五·五、⚠️ 与其它几份清单的分工（**别混**）

科研写作有**六个互不重叠的轴**。混着查会互相误报。

| 轴 | 文件 / 脚本 | 问什么 |
|---|---|---|
| **① 措辞的文体适配** | `写作禁用词与句式清单.md` + `check_persona.py` C8 | 这个词在这个文体里合适吗？（口语节拍 vs 口语化）|
| **② 说法准不准** | **`内容复盘` §三 八条标准** | 自足 / 可答 / 有出处 / 不越原文 / 不哄 / 不设问 / 科学表述 / 维度齐 |
| **③ 像不像他写的** | **本文件** | 术语层 / 引据层 / 立场层 —— **身份轴** |
| **④ 像不像人写的** | `PPT文稿去味清单.md` | AI 味、套话 |
| **⑤ 引用与断言** | `check_language.py` | 引用自足 · 排他性断言 · 空泛量词 · 缩写 · 数字口径 |
| **⑥ 身份匹配机检** | `check_persona.py` C1–C7 | 过度保守 · 越级 · 引据悬空 · 回指 · 书面语 · 长句 |

**② 与 ③ 最容易混**（我自己就混过）：

| | ② 说法准不准（内容复盘） | ③ 像不像他写的（本文件） |
|---|---|---|
| **标准 4「不越原文」** | 问**证据强度**：原文说得有这么强吗？ | — |
| **C2「越级表述」** | — | 问**立场**：这个口气学生拿得住吗？ |
| 例 | 「没达标」→「相对疗效尚未确立」 | 「这证明了」→「这项研究提示」 |

**② 管"别把人家的话说重"，③ 管"别把自己的位置站高"，两者不同。**

> **② 的完整八条标准在 `内容复盘_调整类型与经验教训_20260914.md` §三**——
> 它从你实际纠正里提炼，比本文件更贴近你的判断习惯，**出稿前应一并过**。
> 本文件只补它没有的**身份轴**。

## 六、定稿前的三问自查（**逐页过**）

拿最终稿，逐页问：

- [ ] **术语层**：这页有没有我用着不顺、被追问会卡住的词？
- [ ] **引据层**：这页每条引用，我能立刻说出是哪一篇吗？
- [ ] **立场层**：这页的口气，是"学生汇报"还是"专家断言"？
- [ ] **界限**：有没有列导师组自己的成果？有没有讲导师的常识？
- [ ] **边界 1**：我为措辞软化而删掉的信息，是不是本该指出来的？
- [ ] **边界 2**：这页是不是通篇"可能/似乎"，没敢下任何一个判断？

> 六项全过，才算"读起来是你写的"。
