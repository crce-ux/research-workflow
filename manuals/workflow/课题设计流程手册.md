## 二、D1 · 子假设落地

**目标**：把"研究假设"拆成**可操作、可证伪**的子假设。

### 每个子假设必须落地四项

| 项 | 要写清什么 | 反例（不合格） |
|---|---|---|
| **变量** | 自变量 / 因变量 / 协变量，各自的类型（连续/分类） | "分析 EEG 与疗效的关系"——哪个频段？哪个疗效指标？ |
| **测量** | 用什么工具、什么参数、谁评 | "用 PANSS"——总分还是分量表？谁评？盲否？ |
| **时点** | 基线 / 治疗中 / 终点，各测什么 | "治疗后测"——治疗 4 周还是 8 周？ |
| **证伪条件** | **什么结果算假设不成立** | 缺此项 = 不可证伪 = 不是科学假设 |

### ⚠️ 证伪条件是本步的灵魂

不能只写"我们预期 A 与 B 正相关"，要写"**若 A 与 B 无关（p>0.05 且效应量 < X），则假设 H1 不成立**"。

> **为什么**：没有证伪条件，事后无论结果如何都能"解释得通"——这正是返工总表里
> 「结论无边界」的根源。**写下来，是对自己未来诚实的唯一保障。**

### 与预估结果的分层

建议区分**主假设**（决定成败）与**探索性假设**（产生新问题）。二者在统计上待遇不同：
- 主假设 → 需多重比较校正、需样本量支持
- 探索性 → 明确标注"探索性"，不做校正但**结论不可当定论**

## 三、D2 · 样本量估算

### 🔴 铁律：效应量不可照搬文献

> ⚠️ **文献报告的效应量多来自"患者 vs 健康对照"**。
> 若你的比较是"**患者组之间**"（如应答者 vs 非应答者、MECT vs MST），
> **效应量必然更小**——直接代入会严重低估所需样本量。

**做法**：给出**乐观 / 保守两套估算**，并说明各自假设来源。

### 估算四要素

| 要素 | 说明 | 常取值 |
|---|---|---|
| **效应量** | 来自证据表，但须降级 | 乐观 = 文献值 × 0.7；保守 = 文献值 × 0.5（经验值，需说明） |
| **检验效能** | 1−β | 通常 0.80 |
| **显著性水平** | α | 0.05（双侧） |
| **脱落率** | 按同类研究估计 | 精神科队列 15–30% |

### 多重比较校正（与 D1 联动）

比较次数决定校正方式（Bonferroni / FDR / 层级门控）。**先定比较策略，再定样本量**——
否则样本量算完发现校正后效能不足，要返工。

### 交付形式

```
主分析样本量：N = ___（效能 0.80，α=0.05，效应量 d=___）
保守情形：    N = ___（效应量 d=___）
+ 脱落率 ___% → 需招募 N = ___
+ 与队列现有规模的对比（可行性校验，接 D4）
```

## 四、D3 · 入排标准与分组定义

### 纳入 / 排除

| 维度 | 要点 |
|---|---|
| **诊断** | 诊断系统（DSM-5 / ICD-11）+ 评估工具（SCID） |
| **年龄 / 病程** | 与文献可比性（影响 D2 的效应量外推） |
| **排除** | 共病（物质依赖、器质性脑病）、妊娠、ECT 禁忌 |
| **用药** | 是否限制合并用药、是否要求洗脱期 |

### 分组定义 ⚠️ 阈值必须写明出处

> 返工总表教训：「被问'凭什么这么分组'」→ 根因是**阈值来源未写**。

例：
- TRS 定义 → 写明依据（**Kane 标准** / **《难治性精神分裂症中国专家共识》** / TRRIP 共识）
- 应答定义 → 写明阈值来源（如 PANSS 减分率 ≥ 50%，或 BPRS 改善 ≥ 20%）
- **不要**只写"难治性患者"或"应答者"而不给判据

### 与文献分组的一致性检查

若本课题要与某篇文献的结果比照，**入排与分组定义须先对齐**——
否则"我们的结果和他们不一致"可能只是定义不同，不是真矛盾。

## 五、D4 · 可行性

| 维度 | 要落实什么 |
|---|---|
| **病例量** | 本院 / 分中心年门诊量 × 符合入排比例 = 可招募数（须与 D2 需求数对比） |
| **机时** | 设备数 × 每例耗时 × 随访次数；与临床排班冲突否 |
| **时间窗** | 与主队列 / 主 RCT 的衔接时点（错过窗口 = 收不到数据） |
| **人力** | 评估者、技师、盲法维持 |
| **资金** | 耗材、检查费、劳务 |

### 风险与应对

每项风险写：**风险 → 概率 → 影响 → 应对**。
例：「主 RCT 入组慢」→ 中 → 高 →「预留补招募渠道 / 申请延长周期」。

> ⭐ **可行性最常见的一票否决**：**可招募数 < 样本量需求**。
> 此步必须做**数字对比**，不能只写"预计可满足"。

## 六、D5 · 伦理与数据管理

### 伦理审查
- 伦理委员会名称、批件号（申请中须标注）
- 知情同意形式（书面 / 口头 + 见证）
- 弱势群体保护（若有）

### 数据管理计划
- 存储位置与权限（谁能访问）
- 脱敏规则（ID 映射表存放处）
- 保存年限（通常 ≥5 年）
- 共享范围（是否公开、何时公开）

### 预注册与透明度
- 注册平台（ChiCTR / ClinicalTrials.gov）与注册号
- **注册时点应早于入组开始**——事后注册会削弱可信度
- 与分析方案的一致性（偏离须报告）

## 六·五、收敛判据 · 裁决四档（2026-09-19 新增）

D1–D5 走完后，对**整个方案**给一个明确结论。借鉴 Research-OS-Studio
`idea-review`（MIT）的裁决措辞——**先定档，再写理由**。

| 档 | 含义 | 下一步 |
|---|---|---|
| **`READY FOR USER DECISION`** | 当前材料**未见阻断** | 提交导师决策——⚠️ **仍未科研验证** |
| **`REVISE`** | 有**可修复**的问题 | 列出问题清单，逐条改后复评 |
| **`RETHINK`** | 核心机制存在**证据支持的**根本问题 | 回到立论层，非修修补补 |
| **`EVIDENCE GAP`** | 关键原文／证据缺失 | 补文献或补检索，**不是方案本身的问题** |

### ⚠️ 三条纪律

**1. 裁决是「建议」，不是「结论」。**
方向由导师定（见 SOUL「调研的角色边界」）——本档位只说明**材料是否够用**，
不替导师决定做不做。

**2. 建议放弃，必须给具体的 prior work 或明确反证。**

> 🔴 **分数、相似感、"生成者排名"、"我觉得新意不够"——都不算理由。**

这条与本库既有的「零证据复核」「立论表述收紧」同源，
但把门槛写死了：**说"不行"要有出处，感觉不算。**

**3. `EVIDENCE GAP` 不等于方案不好。**
缺证据是**待补**，不是**待否**。判成 RETHINK 之前，
先确认关键原文是否真的读到过（很多"机制不成立"其实是"没读到那篇"）。

### 与 D 段的关系

| 档 | 通常卡在 |
|---|---|
| `REVISE` | 多为 D3（分组阈值无出处）· D4（可招募数没算） |
| `RETHINK` | 多为 D1（假设不可证伪）· 论证链断裂 |
| `EVIDENCE GAP` | 多为 §七 映射表里"研究空白"只有 1 条独立证据 |

## 七、证据表 → 设计书 的映射（跨段衔接）

| 设计书章节 | 证据来源 | 注意 |
|---|---|---|
| 2.2 现有研究证据 | A2 证据表「关键结果」列 | 数字须回原文核过 |
| 2.3 研究空白 | 证据表 + 收口判据（**≥2 条独立证据**）| ⚠️ 同源团队/同队列不算独立 |
| 2.4 研究假设 | 证据表 + 收口判据 | 假设须能被证伪（D1） |

| 5.x 统计方案 | 证据表「研究设计」列 | 方法学参照 |

## 八、踩坑清单（复用前必看）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | **D2 效应量照搬文献的"患者 vs 对照"值** | 患者组间比较效应量更小；给**乐观/保守两套** |
| 2 | **分组阈值来源不明** | 写明依据（Kane / 中国专家共识 / TRRIP），可被追问 |
| 3 | **样本量只给单点值** | 给区间 + 假设来源 + 脱落率 |
| 4 | **先算样本量后定比较策略** | 先定多重比较策略，再算样本量 |
| 5 | **可招募数未与需求数对比** | D4 必须做数字对比，不能只写"预计可满足" |
| 6 | **伦理/数据管理后补** | 与主 RCT 衔接时最容易卡；D5 与 D1-D4 并行推进 |
| 7 | **预注册晚于入组** | 注册应早于首例入组 |
| 8 | **设计书依据追不到证据表** | 逐条审计：每条依据 → 证据表条目 |
| 9 | **入排定义与所引文献不一致** | 先对齐定义，再谈结果是否矛盾 |
| 10 | **假设无证伪条件** | D1 四项必须齐全，尤其"证伪条件" |
