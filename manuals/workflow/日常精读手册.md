## 〇、P 段的定位

**P 段不占档**——它是**跨项目的常驻活动**，为 A/B/C/D 各段共同供料。

```
日常（人工筛选 + 理解）
   选文献 → 读全文 → 写笔记 → 回填文献表
         ↓
   文献精读/_文献表.xlsx
         ↓  按主题标签筛选 → 补「对本课题的意义」→ 分区重组
   A2 证据表（对接时是「搬运」而非「重做」）
```

> ⭐ **P 段的价值**：把 A1 检索、A2 建表、A3 讲解的**部分工作量前移到日常**——
> 等真要写时，这些文献**已过人工筛选与理解**，省去重复劳动。

## 一、选什么读（**判据**）

> ⚠️ **不设"必读清单"**——读什么由课题需要驱动。
> 但**选与不选要有判据**，不能凭"看着眼熟"。

### 该读的

| 信号 | 说明 |
|---|---|
| **竞争文献** | 同一个问题上**别人也在做**的——优先级最高 |
| **方法学模板** | 研究设计/范式/统计写得好的，可照着设计自己的 |
| **立论接口** | 能支撑你某个论点的关键证据 |
| **领域现状** | 权威综述/共识——**只用于背景，不当作一手证据** |

### 不该读的（或只扫读）

| 信号 | 处置 |
|---|---|
| 只与主题沾边 | ❌ 不读 |
| 结论已被更新的研究取代 | ❌ 不读（**除非要写"研究演变"**）|
| 只能拿到摘要 | ⚠️ **可读，但必须标注"仅摘要"**（见 §二）|
| 二次转述 | ❌ 不读——**追到原始文献**（见 `术语表.md`「二手陈述」）|

> ⚠️ **本库最贵的一类问题**（14 处）就是**把二手陈述当一手证据**。
> **P 段是拦截它的第一道关**——在这里读原文，比在 A3 阶段才发现强得多。

## 二、读到什么程度（**分级**）

> 与 A 段的三级筛选（A/B/C 类）**不同**——前者按文献类型分，后者按**阅读深度**分。

| 级 | 读到哪 | 产出 | 适用 |
|---|---|---|---|
| **扫读** | 标题 → 摘要 → 图表 → 结论 | 一句话摘要 + 判定 | 判"值不值得深读" |
| **泛读** | 扫读 + 方法 + 结果 | 要点笔记 | 背景性、支撑性文献 |
| **精读** | **全文逐段** + 批判性思考 | 完整精读笔记（见 §三）| 竞争文献、方法学模板、关键证据 |

### ⚠️ 阅读深度必须标注

**同一篇文献，读到什么程度，直接决定它能支撑什么结论**：

| 读到 | 能支撑 | **不能**支撑 |
|---|---|---|
| 仅标题 | ❌ 几乎不能 | 任何实质断言 |
| 仅摘要 | **作者自述的结论** | 方法细节、局限、亚组 |
| 全文 | 精确范围与条件 | （仍需按 `核查方法/01` 判语境）|

> 🔴 **读的深度要写进笔记**——否则日后会把"只读了摘要"当成"读过全文"。
>
> **实测教训**（SMART-CAT Li 2026）：全文未获取，笔记按
> **🟢摘要 / 🟡注册库 / 🟡方案论文 / 🟡院方通稿** 四源交叉并**逐条标注来源等级**。
> **这条做法应成为惯例**——见 `核查方法/01` 的三态词汇。

## 三、笔记怎么写

### 3.1 笔记文件命名

```
<项目名>/精读笔记_<第一作者><年份>_<主题>.md
```

### 3.2 笔记结构（**精读级**）

```markdown
## <论文标题>
**PMID** / **DOI** / **年份** / **期刊**（用英文原名）
**标签**：#主题 #方法 #人群
**阅读深度**：全文 / 摘要 / 前三页

### 一句话结论
> 用一句话概括核心发现

### 研究设计
设计类型 / 样本（N、来源、入排）/ 干预或暴露 / 主要结局

### 关键结果
| 指标 | 效应量 | 95%CI / P |
（**回原文对应语句核过**）

### 方法亮点与局限
### 与本项目的关联
### 可引用的关键句
```

### 3.3 笔记的三条硬规则

**① 每个数字必须能指向原文的具体位置**
指不出 → 不能写成断言（沿用 `文本迭代自查流程.md` §五 实证纪律）。

**② 转述必须回读完整段落**
尤其是"作者说…"这类归因句。
> 实测教训：局限性段落**开头**讲样本量小，**后半段**才写着
> "limiting the usefulness of this model"——只读前半段会误判。

**③ 竞争文献要写"威胁评估"**
不只是一条笔记，要回答：**它做到了什么、没做到什么、我们的差异在哪**。
> 见 `文献精读/TRS_EEG/` 里的竞争文献处理方式。

## 四、怎么回填文献表

### 4.1 真源与生成物

```
_文献表.json        ← 真源（脚本读它，日常追加此文件）
_文献表.xlsx / .md  ← 生成物（15 列）
```

```bash
cd "<vault>/文献精读"
python "../scripts/build_daily_ref.py" --data "_文献表.json" -o "."
```

### 4.2 列结构（**15 列 = 11 对齐 + 4 管理**）

| # | 列 | 备注 |
|---|---|---|
| 1–11 | 文献·DOI / 作者·年份 / 研究设计 / 人群(P) / 干预暴露(I/E) / 对照(C) / 主要结局(O) / 关键结果 / 局限 / 期刊 IF / 期刊分区 | **与证据表前 11 列同名同序** |
| 12–15 | 主题标签 / 精读状态 / 笔记链接 / 入库日期 | 管理列 |

> ⚠️ **这 11 列对齐是 P 段设计的目的**——
> **对接 A2 时只需补第 12 列「对本课题的意义」+ 按叙事重组。**

### 4.3 质量线（**必须守，否则对接时仍返工**）

- [ ] **「关键结果」回全文核对**——摘要常不载样本量与效应量，
      而**精读的价值恰在于有全文**
- [ ] **「人群」列填全样本量**（返工总表「被追问答不上样本量」的根因就是摘要未载、未调全文）
- [ ] **期刊 IF 用官方 JCR 值并标年份**：`6.6 (2025 JCR)`
- [ ] **分区写「中科院（标版本）+ JCR」**：`中科院医学2区(2025) / JCR Q1`
      —— ⚠️ 中科院分区有基础版/升级版差异且逐年变动，**不写口径等于没写**
- [ ] 中文刊/预印本/新刊查不到 → **允许留空**，不硬填

**精读状态取值**：`⬜未读 / 🔄在读 / ✅已精读 / 📝笔记完成`

## 五、对接 A 段（P → A2）

```
文献表_文献表.xlsx（15 列）
    │ ① 按「主题标签」筛选相关条目
    │ ② 补第 12 列「对本课题的意义」（需课题上下文，**人工完成**）
    │ ③ 按叙事分区组织（B1/B2/B3/B4）→ 模块X_evidence.json
    │ ④ build_evtab.py --data 模块X_evidence.json --module 模块X
    ▼
证据表_模块X.xlsx（12 列）
    └→ 逐篇讲解 / 综述 / PPT（走《文献调研流程手册》A3 起）
```

> ⚠️ **第 ② 步必须人工**——「对本课题的意义」需要课题上下文，
> **不能由脚本推断**，也不能由 AI 代填（属判断，不属于搬运）。
